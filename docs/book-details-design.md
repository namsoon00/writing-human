# 독서와 쓰기의 아홉 가지 요소 독립 설계

쓰는 인간의 책갈피, 장서표, 원문 쪽지, 밑칠, 쪽수 장식, 제본 흔적, 날짜인, 문장 구분표, 압화를 각각 하나의 독립된 구성요소로 다룬다. 아홉 가지 요소는 같은 책과 종이의 분위기를 공유하면서 모양·색·표시 여부를 개별적으로 선택한다. 이 문서의 모양 선택과 설정 화면은 Flutter 앱 코드에 연결되어 있다. 시각 검수와 실제 기기 검증 범위는 verification.md의 이번 작업 기록을 따른다.

## 독립성의 기준

- 각 요소는 `enabled`, `variant`, `tone`을 자체 값으로 가진다. 하나를 바꾸거나 기본값으로 돌려도 나머지 아홉 요소, 종이·잉크·글꼴, 줄 가이드, 펜 움직임은 바뀌지 않는다.
- 꾸밈 설정과 기록 데이터를 분리한다. 이름, 원문, 구절 표시 범위, 기록 시작일은 꾸밈을 꺼도 보존한다. 설정 화면의 미리보기는 합성 예시이며 사용자 기록을 생성하거나 수정하지 않는다.
- 모든 요소는 다른 여덟 요소를 꺼도 사용할 수 있다. 페이지 본문이나 장식 위젯의 존재를 다른 요소의 필수 조건으로 삼지 않는다.
- 현재 설정 범위는 라이브러리 전체다. 특정 책만 다른 모양으로 표시하는 상속·덮어쓰기 규칙은 두지 않는다. 독립성은 요소 사이의 독립을 뜻한다.
- 앱은 마지막 글이나 빈 종이로 바로 열린다. 꾸미기를 시작 조건으로 요구하지 않는다.

## 공통 조형 규칙

기본 종이는 #F7F2E8, 본문은 #302C27, 브랜드 잉크는 #70472F다. 포도 #7A4A4A, 올리브 #4E5A42, 회청 #4C607A를 공통 색으로 쓴다. 회청은 작은 실제 텍스트에도 사용할 수 있도록 기존 표지의 회청보다 어둡게 정했다. 연필 기본선은 #82796D다. 쪽지의 네 바탕색은 #FCF8ED, #FDFCF7, #F6E6D9, #EDECE6이다.

본문·장서표의 제목과 조작 문구는 앱의 현재 글꼴 정책과 번들 대체 글꼴을 따른다. 사용자가 고른 본문 서체를 꾸밈 변경으로 교체하지 않는다. 서체의 제공 범위와 표기는 기존 서체 정책을 따른다.

장식 선은 대체로 0.5–1.2 logical px, 그림자는 낮은 농도로 제한한다. 장식의 균일한 미세 결을 정적으로 그리며 타이핑마다 무작위로 바꾸지 않는다. 종이·실·천의 인상이 실제 문장보다 강해지지 않게 한다.

색을 고르는 칩에는 색 이름과 선택 상태를 함께 표시한다. 날짜와 장서표 이름처럼 의미가 있는 글자의 색은 가장 어두운 기본 종이에서도 대비를 점검한다. 꾸밈을 끈 메타데이터에는 기존 읽기용 글자색을 쓴다.

## 1 천 책갈피

### 조형과 배치

상단에 고정된 가는 세로 천이다. 본문 영역으로 내려오지 않으며, 상단 오른쪽의 새 종이 버튼과 떨어져 놓는다. 화면 기준 폭 13, 길이 38이고 키보드·가로 화면에서는 길이를 23으로 줄인다. 독립 견본에서는 폭 17, 길이 64로 재질과 끝 모양을 보여 준다. 책 표지와 페이지 미리보기에서는 각 면의 크기에 맞춰 줄인다.

세 모양은 아래 끝의 실루엣만 바꾼다. 끝의 깊이는 폭의 42%와 높이의 20% 중 작은 값으로 제한해 작은 책 표지에서도 과하게 파이지 않게 한다. 사선은 낮게 비스듬한 끝, 제비꼬리는 중앙이 파인 끝, 둥근 끝은 부드러운 곡면이다. 광택을 줄인 얕은 명암, 1.7px 간격의 가로 결과 2.1px 간격의 세로 결, 양끝의 작은 박음질을 정적으로 유지한다. 색은 책·종이·다른 장식의 선택과 독립적이다.

### 상태와 역할

저장된 활성 글에만 나타난다. 새 빈 초안에는 나타나지 않는다. 보관함에서는 활성 기록·활성 책에, 페이지 목록에서는 현재 페이지에 나타난다. 숨겨도 활성 위치·페이지 선택·재실행 복원은 유지한다. 현재 페이지의 선택 상태와 ‘이어서 쓰는 글’ 접근성 이름은 별도로 제공한다.

현재 위치를 읽는 시각 표식으로 설계했다. 임의의 페이지를 꽂아두는 수동 책갈피나 책별 마지막 위치 저장 기능으로 표시하지 않는다. 즐겨찾기와도 별개다. 리본 자체는 입력을 가로채거나 드래그되지 않는다.

## 2 장서표

### 조형과 배치

보관함에서 책을 연 첫 부분에 둔다. 밝은 면지 위에 잉크 표식, ‘나의 장서표’, 책 제목, 편·쪽수와 저자, 소유자 이름 조작부를 순서대로 배치한다. 소유자와 저자의 자리를 섞지 않는다.

이중 테두리는 0.65px 외곽선과 6px 안쪽의 0.5px 선이다. 면지에는 낮은 명암과 짧은 섬유 결을 두고 잉크 표식도 선택한 장서표 색으로 인쇄한다. 모서리 장식은 네 귀퉁이에만 짧은 직각선을 둔다. 잉크 표식형은 사방의 선을 걷어내고 기존 잉크 표식과 짧은 하단선으로 중심을 잡는다. 세 모양 모두 같은 내용과 이름 편집 동작을 가진다.

책 상세의 바탕은 책의 내지 색과 결을 사용한다. 장서표 바탕은 그 내지에서
밝기를 조금 높이고, 새 종이 버튼과 검색의 포커스 선에는 브랜드 잉크를 사용한다.
압화에는 선택한 색을 적용한다.

### 상태와 조작

이름이 없으면 ‘이름 남기기’를, 이름이 있으면 ‘○○의 책’을 표시한다. 작은 연필 아이콘과 ‘장서표 이름 남기기/고치기’ 툴팁으로 편집 동작을 알린다. 소유자 이름과 편집 안내를 같은 긴 문장으로 인쇄하지 않는다. 이름 편집은 취소·저장이 있는 별도 입력창에서 한다. 이름을 비우고 저장하면 소유자 이름만 지운다.

꾸밈을 끄면 테두리·표식·장서표 소제목을 숨기고 책 제목, 요약, 소유자 편집은 평문으로 남긴다. 책 없는 기록에는 장서표를 만들지 않는다. 보관함의 스크롤 안에 놓아 큰 글씨·작은 화면에서도 본문을 밀어내지 않는다.

## 3 원문 쪽지

### 조형과 배치

접힌 원문 요약과 원문 편집창에 같은 쪽지 모양을 적용한다. 네 바탕색은 종이 설정과 별개의 값이다. 접힌 요약은 가로 12·세로 10, 펼친 편집은 20을 기준으로 한다. 클립·접힘이 있는 쪽은 오른쪽 30의 여백을 확보한다. 원문 입력창의 테두리를 없애 실제 글이 쪽지 위에 놓이게 한다. 모서리에는 실제 글자가 들어가지 않도록 여백을 확보한다.

가장자리 선은 왼쪽의 1px 선과 옅은 0.5px 눌림선이다. 종이 아래 가장자리는 0.35px 이내의 고정된 굴곡으로 표현하고, 섬유는 가장자리의 낮은 명암으로만 그린다. 종이 클립은 위쪽 오른편에 작은 철사 윤곽을 걸친다. 접힌 귀퉁이는 오른쪽 위의 13px 삼각면과 얕은 접힘선을 쓴다. 클립·접힘은 정적인 장식이며 터치 대상이 아니다.

### 상태와 조작

원문이 없으면 작성 화면의 요약 쪽지를 숨긴다. ‘더 보기 → 원문 메모’에서는 빈 입력창을 열 수 있다. 원문은 실제 TextField로 편집하며 기존 취소·저장을 사용한다. 원문의 책·쪽수 등 출처는 현재 원문 메모 안의 텍스트로 남긴다.

꾸밈을 꺼도 원문 요약·편집·저장을 계속 제공한다. 꾸밈 선택은 원문 문자열을 바꾸지 않는다. 빈 초안에서 모양을 살펴보는 것으로 기록을 생성하지 않는다.

### 원문 등록 화면

원문 보기와 같은 종이 색·결과 쓰는 인간체를 사용한다. 등록을 연 책의 종이를
따르고, 책이 없으면 기본 설정을 따른다. 제목 바로 아래에 테두리 없는 원문 쪽지를
두며 선택한 쪽지의 색과 클립·접힘을 사용한다. 붙여넣기와 사진에서 가져오기는
쪽지 바로 아래에 둔다. 사진 메뉴에서 한 페이지와 문단 중 고를 수 있다.

보관할 책과 출처는 종이 위의 얇은 구분선으로 나눈다. 좁은 화면이나 큰 글씨에서는
항목 이름을 입력 위로 올린다. 하단의 작은 저장 버튼은 입력이 유효할 때 켜진다.
공유 안내는 보조 동작으로 둔다. 사진 검수에서도 같은 종이와 기록란을 사용한다.

## 4 밑칠

### 조형과 배치

선택한 글자 뒤에 반투명 색을 깐다. 기본은 옅은 황토빛이며 글자색과 독립된 색 네 가지와 농도 세 가지를 고를 수 있다. 본문 행 높이·글자 간격·페이지 분할은 유지한다. 설정의 고정 구절과 실제 원문·필사·페이지 미리보기에서 같은 표현을 쓴다.

### 상태와 조작

구절을 선택하고 선택 메뉴의 ‘밑칠하기’를 누른다. 표시 범위 안의 일부를 선택하면 ‘밑칠 지우기’로 그 부분만 지울 수 있다. 인접·겹치는 표시는 범위를 정리한다. 빈 선택과 한글 조합 중에는 표시 추가를 하지 않는다.

표시 데이터는 페이지의 UTF-16 범위다. 수정 뒤에도 남은 글자의 표시를 이동·분할하고, 새로 삽입·대체한 글자는 표시하지 않는다. 표시 범위가 있더라도 꾸밈을 끄면 밑칠을 감춘다. 다시 켜면 남아 있는 범위를 같은 모양으로 보여 준다. 숨긴 동안의 본문 편집에도 범위 이동을 적용한다.

composing의 기본 밑줄은 별개로 유지한다. 표시 설정을 바꿀 때 TextEditingController를 교체하거나 text·selection·composing 값을 되쓰지 않는다. 페이지 미리보기에도 같은 표시 스타일을 사용한다.

## 5 쪽수 장식

### 조형과 배치

쪽수 양옆의 가로 23, 세로 12 영역에 둔다. 선과 점은 짧은 횡선과 점, 마름모는 짧은 선 끝의 작은 다이아몬드, 작은 잎은 얇은 줄기와 곡선 잎이다. 좌우 문양은 서로 마주보며, 쪽수와 8px씩 떨어진다.

### 상태와 조작

쪽수 버튼·좌우 넘김·보조 화면의 페이지 추가 동작과 터치 영역을 유지한다. 장식 자체는 버튼이 아니다. 꾸밈을 끄면 쪽수만 남는다. 폭이 110px보다 좁거나 시스템 글자 확대가 1.5배를 넘으면 설정값을 보존한 채 장식을 생략한다. 이후 공간이 넓어지면 다시 나타난다.

긴 쪽수와 세 자리 이상의 페이지 수에서도 조작부가 우선한다. 문양을 보기 위해 실제 쪽수나 접근성 설명을 이미지로 만들지 않는다.

## 6 제본 흔적

제본 흔적은 책의 재질 표현으로 쓰며 꾸밈 목록에서는 선택하지 않는다.
기존 책이나 기본 스타일에 저장된 제본 값은 렌더링에 계속 사용한다.

### 조형과 배치

종이 왼쪽 가장자리 18px 안쪽에만 얕은 제본 음영을 둔다. 본문 패딩은 유지한다. 직조 띠는 위아래 안쪽 4px 위치의 28×4 띠와 실 결이다. 실 제본은 두 개의 작은 바늘구멍을 잇는 둥근 실 고리로 표현해 화살표처럼 보이지 않게 한다. 천 책등은 더 좁은 두 방향 직조선으로 구분한다.

책 표지에서는 같은 모양을 축소해 책등에만 적용한다. 표지의 린넨 바탕·색·책 제목은 그대로 유지한다. 본문 종이를 회백지로 바꾸어도 고른 실 색은 바뀌지 않는다.

### 상태와 조작

화면을 누르거나 입력할 때 움직이지 않는다. 꾸밈을 끄면 추가 제본 층과 안쪽 제본 음영을 숨기고, 종이 질감과 본문은 유지한다. 책 없는 낱장 기록도 제본의 물성을 선택할 수 있다. 이는 기록을 자동으로 책에 묶는 동작이 아니다.

## 7 날짜인

### 조형과 배치

보관함 기록 행과 ‘더 보기’의 기록 시작일에 둔다. 사각·타원 인장은 약 0.75px 선과 낮은 농도의 잉크 번짐을 사용한다. 고정된 아주 짧은 선 끊김으로 압인 느낌을 주고, 날짜 활자는 외곽선 없이 숫자와 간격으로 표현한다. 인장 질감은 날짜 글자에 겹치지 않는다. 실제 텍스트를 유지하고 회전시키지 않는다.

표시값은 `2026 . 11 . 10` 형태이며 글자 크기는 11을 기준으로 시스템 확대를 따른다. 날짜를 감싸는 좌우 여백은 10, 상하 여백은 6이다. 선택된 인장의 자간은 0.85를 사용한다. 작은 글자에 사용하는 회청은 #4C607A다.

### 상태와 날짜의 의미

날짜는 페이지를 새로 보관한 기기의 현지 날짜이며, 수정할 때마다 바꾸지 않는다. 표시 설정을 바꾸거나 다른 시간대에서 열어도 저장된 날짜를 그대로 표시한다. 과거 기록의 날짜를 현재 날짜로 추정하지 않는다. 날짜가 없으면 도장도 만들지 않는다.

꾸밈을 끄면 외곽선과 장식 자간을 줄이고 날짜를 평문으로 남긴다. 스크린리더에는 ‘기록 시작일’과 날짜를 함께 읽는다. 날짜인의 색·모양은 날짜값과 독립적이다.

## 8 문장 구분표

같은 책에 필사 기록이 둘 이상 있을 때 기록 행 사이에만 나타난다. 세 점·짧은 선·작은 꽃의
가벼운 갈색 인쇄를 쓰며 색을 독립적으로 고른다. 장서표 앞이나 끝 기록 뒤에 만들지 않는다.
숨겨도 행을 구별하는 여백을 유지한다. 본문·원문·페이지 데이터에는 문자를 쓰지 않는다.

## 9 압화 장식

작은 잎은 줄기와 잎맥, 들꽃은 얇게 눌린 다섯 꽃잎, 고사리는 가는 줄기를 따라 잎 조각을
겹쳐 그린다. 표지와 장서표의 아래 오른쪽·왼쪽·가운데 중 하나를 고른다. 기본은 오른쪽에
작은 올리브 잎이다. 표지에 맞춰 축소하고 장서표에서는 이름 버튼 아래에 별도 영역을 둔다.
장서표 테두리와 별개로 선택하며 입력이나 터치에는 관여하지 않는다.

## 설정 화면과 조합


책별 꾸미기의 책 장식은 ‘책의 겉과 첫 장’과 ‘필사 쪽’으로 나눈다.
첫 항목인 천 책갈피를 펼치면 위의 펼친 책에서 색과 끝 모양을 확인할 수 있다.
각 행은 작은 견본과 현재 모양·색 또는 숨김 상태를 보여 준다. 한 항목을 열면
해당 행 아래에 쓰임 설명과 확대 견본, 옵션을 펼친다. 위의 책은 장식 위치에 맞춰
표지나 펼친 면을 보여 준다. 책별 꾸밈은 선택 즉시 자동 저장한다.
일반 세로 화면에서는 목록을 내리는 동안에도 미리보기를 볼 수 있다.

경로는 `Aa → 책의 디테일`이다. 아홉 가지 요소를 각각 펼쳐 설명, 합성 견본, 꾸밈 표시 스위치, 모양 세 가지, 색 네 가지, ‘이 요소만 기본으로’를 제공한다. 선택은 바로 적용·저장한다. 저장 실패는 같은 화면에 표시하고 최신 선택을 재시도할 수 있다.

꾸밈을 끈 요소는 마지막 모양·색을 기억한다. 꺼진 동안 모양·색 조작부는 비활성화한다. ‘이 요소만 기본으로’는 해당 요소만 표시 상태와 첫 모양·첫 색으로 되돌린다. 다른 요소와 문서 내용은 바꾸지 않는다.

예를 들어 책갈피를 올리브 제비꼬리로 바꾸고 장서표를 끌 수 있다. 이때 장서표 이름은 남고, 원문 쪽지의 미색·연필의 점선·날짜인의 타원은 각각 유지된다. 모든 꾸밈을 끈 상태에서도 쓰기·원문 편집·소유자 이름 편집·날짜 확인·페이지 이동을 할 수 있다.

## 저장과 컴포넌트 경계

`WritingStyle.bookDetails` 아래에 아홉 개의 BookDetailChoice를 둔다. 각 선택은 enabled bool, variant 0–2, tone 0–3을 저장한다. 압화는 placement 0–2를 추가로 선택한다. 스타일을 가진 위젯은 해당 선택만 매개변수로 받으며 전역 설정을 직접 수정하지 않는다.

Book.owner, WritingRecord.source, WritingPage.pencilMarks/writtenOn, Library.activePageId는 기존 기록 데이터다. 꾸밈의 선택값에 복사하거나 꾸밈을 끌 때 지우지 않는다. 설정 화면의 합성 예문·이름·날짜는 저장하지 않는다.

스타일은 기존 settings JSON과 웹 라이브러리 JSON v1을 사용한다. 이전 설정에 bookDetails가 없으면 기본값을 읽고, 잘못된 타입·지원하지 않는 모양·색 번호는 오류로 처리한다. 손상 설정을 이유로 빈 라이브러리로 대체하지 않는다.

동기화는 각 요소의 enabled·variant·tone·placement를 별도로 병합한다. 한 기기의 책갈피 색 변경과 다른 기기의 책갈피 모양 변경을 함께 보존한다. 종이·잉크·글꼴 및 다른 여덟 요소의 변경도 따로 병합한다. 같은 필드의 동시 변경은 기존 로컬 우선 규칙을 적용한다.

## 완료 판정

- 아홉 가지 요소 각각이 단독으로 렌더되고, 세 모양과 네 색 및 숨김을 표현한다.
- 한 요소의 변경·개별 초기화·저장 실패 후 재시도가 나머지 선택과 사용자 기록을 바꾸지 않는다.
- 실제 SQLite 파일을 닫고 다시 열면 모든 선택과 기존 데이터가 복원된다.
- 한글 조합·펼친 선택 영역·스크롤 중 설정을 변경해도 같은 편집 컨트롤러와 입력값을 유지한다.
- 320px 화면과 2배 시스템 글씨에서 설정을 펼치고 선택할 수 있으며, 의미 있는 글자·버튼이 잘리지 않는다.
- 기본색 이외의 날짜/이름 텍스트도 실제 바탕에 충분한 대비를 유지한다.
- 새 선택을 검증한 포맷·분석·테스트와 렌더 결과를 verification.md에 구분해 기록한다.
