# 쓰는 인간

쓰기 도구와 원문 패널은 현재 내지의 색을 옅은 미색에 섞고 종이 결을 줄여 표시한다.
글꼴과 원문 필터 칩은 바탕보다 살짝 밝고, 선택하면 갈색 테두리와 옅은 갈색 면을
사용한다. 켜진 스위치는 밤색과 아이보리, 원문 목록은 먹갈색을 쓴다. 펼친 원문과
필사 본문에는 고른 잉크색을 적용한다.

## 글씨 쓰는 소리

‘쓰기 도구 → 글씨 쓰는 소리’를 켜면 필사 본문에 새 글자를 쓰기 시작할 때
종이에 연필심이 스치는 짧은 소리가 난다. 한글은 다음 음절을 시작할 때 소리가 나고, 같은 음절의
중성·받침을 덧붙이거나 확정할 때 반복 재생하지 않는다. 빠른 입력에는 소리
간격을 두고, 공백·삭제·여러 글자 붙여넣기에는 재생하지 않는다. 글씨 쓰는
소리는 기본으로 꺼져 있으며 잉크 반응과 종이 넘김 소리는 각각 고를 수 있다.

## 책 꾸미기

책 상세의 목차에서 ‘책 꾸미기’를 누르면 해당 책의 설정이 열린다. 책에 묶인
필사에서도 쓰기 도구를 통해 같은 설정을 열 수 있다. 책별 내지는
‘책 꾸미기 → 표지·내지’에서 고른다. 표지와 내지 선택지는 같은 목록에 있다.
쓰기 도구의 ‘기본 종이’는 책 없는 필사에서 열 수 있다.
표지를 고르면 닫힌 책, 내지를 고르면 펼친 책을 보여 준다. 책갈피도 펼친 책에서
확인한다. 펼친 책에는 마지막으로 펼친 쪽의 필사 두 줄과 쪽수가 나온다. 빈 쪽이면 최근에 본문을 쓴 쪽을 보여 준다. ‘책 장식’에서는
첫 항목에서 천 책갈피를 펼쳐 색과 끝 모양을 고르고, 아래에서 장서표·압화 같은
꾸밈을 고른다. 제본 흔적은 책 안쪽의 표현으로 남긴다. 미리보기의 리본은
책등 가까이에 두고 필사 문구와 여백을 나눈다. 장식을 펼치면 쓰임을 한 줄로 설명하고
확대한 견본을 옵션 위에 보여 준다. 선택은 해당 책에 자동 저장되며 뒤로 가기로
화면을 닫는다. 저장에 실패하면 선택을 유지하고 다시 저장할 수 있다.
선택한 적 없는 요소는 기본 설정을 따르며, 책 없는 글의 기본 꾸밈은
`쓰기 도구 → 책의 디테일`에서 바꾼다.

## 책장

작성 화면 왼쪽 위 ‘책장’을 누르면 책장이 열린다. 노트가 세 권까지는 최근 노트의
표지를 크게 보여 준다. 네 권부터는 위에 최근 노트의 작은 표지와 제목을 놓고 아래
선반에는 세 권씩 놓는다. 표지나 최근 노트 영역을 누르면 바로 쪽이 열린다.
좁은 화면에서는 두 권씩 놓는다. 표지 아래 점 세 개로 책 상세를 연다. 위쪽 돋보기에서 노트 제목을 찾고 ‘새 노트’로 책을 만든다.
‘내 글’에서는 필사 한 편을 종이 한 장으로 보여 준다. 첫 두세 줄 아래에 노트 이름과
기록 날짜를 표시한다. 종이를 누르면 필사가 열리고, 돋보기에서 찾은 종이를 누르면
검색한 대목이 열린다. ‘책장’과 ‘내 글’은 같은 위치의 버튼으로 오가며, 보관함을
열어 둔 동안 각 목록이 보던 위치를 기억한다. 책 없이 쓴 글도 같은 방식으로 표시한다.

책장에 ‘연습장’ 한 권을 둔다. 처음 열 때 책에 속하지 않은 글을 연습장에 모은다.
표지를 누르면 기록의 첫 두세 줄을 담은 종이 목록이 열리고, 종이를 누르면 이어 쓴다.
‘새 종이’는 연습장에 쓰고, 묶고 싶은 글은 쓰기 도구의 ‘다른 책으로 옮기기’로 보낸다.
연습장은 편집기, 내지와 책 꾸미기를 일반 노트와 공유한다.

## 한 권의 목차와 내지

책 상세는 책 제목과 기록·쪽 수를 내지 한가운데 보여 준다. 책마다 마지막으로 펼친
쪽을 저장한다. 앱을 다시 열어도 표지나 `이어서 쓰기`로 그 쪽을 열 수 있다. 버튼 아래에
열릴 쪽수를 표시한다. 목차는
그 쪽이 속한 기록에 책갈피를 표시하고, 제목을 누르면 해당 기록의 첫 쪽을 연다.
새 종이는 목차 제목 옆에 둔다.

상단에서 원문을 열고, 더 보기에서 책 안 검색, 이름, 장서표, 표지·내지, 즐겨찾기,
PDF를 찾는다. 목차·필사·원문은 책의 표지 색과 내지·제본을 공유한다.

## 기록 보관과 문장 찾기 · 2026-11-11

쓰는 화면의 `쓰기 도구 → 기록 보관`에서 전체 백업 파일을 내보내거나 가져온다.
백업 파일은 32MB까지 지원한다.
가져오기 전에 백업 날짜와 책·필사·쪽 수를 보여 준다. 기존 기록과 합치며 내용이
충돌하는 필사는 별도로 보관한다. 빈 보관함에 가져오면 백업의 설정과 마지막 위치도
복원한다. 같은 메뉴에서 현재 필사를 TXT, 현재 책을 PDF로 내보낼 수 있다.
책 보관함에서도 책 PDF를 선택할 수 있다. TXT와 PDF에는 필사 본문을 담는다.

`책장 → 내 글`에서 본문·책 이름·저자·필사 제목·기록 날짜를 검색한다. 본문
검색 결과를 누르면 해당 쪽의 문장이 보이는 위치로 이동한다.


책 안에서 오른쪽 위 `+`를 누르면 현재 필사의 끝에 빈 쪽을 저장하고 그 쪽을 연다.
빈 책에서는 첫 쪽을 저장한다. 책 밖의 `+`로 연 새 종이는 첫 입력까지 초안으로 남는다.

## 쓰는 종이와 형광펜

키보드가 열린 상태에서 종이 여백이나 마지막 글줄 아래의 빈 공간을 누르면 입력 위치를
유지한 채 키보드가 닫힌다. 본문과 입력 가능한 마지막 줄을 누르면 그 위치에서 입력한다.
본문이 화면을 채워도 하단 오른쪽의 키보드 아이콘으로 한 번에 내릴 수 있다.
키보드가 닫히면 그 자리에 ‘쓰기 도구’가 돌아온다. 한글 조합 중에는 현재 입력을 유지한다.
키보드를 여닫아도 제목과 종이 위쪽은 같은 위치에 두고, 쓰는 줄이 가려질 때
입력기가 필요한 만큼 스크롤한다. 글은 계속 자동 저장한다.

본문의 글자 위에서 길게 누른 채 끌면, 손가락이 지나가는 범위를 반투명한 형광펜
색으로 바로 보여 준다. 손을 떼면 밑칠을 저장한다. 제자리에 길게 누르기만 하거나
빈 여백에서 시작하면 표시하지 않는다. 커서 위치와 한글 조합을 유지하며,
이 동작에서 선택 손잡이나 메뉴를 띄우지 않는다. 이미 밑칠한 글을 다시 그어도
색이 겹치거나 지워지지 않는다.

## 종이에 남는 잉크

글자 사이의 짧고 가는 세로획이 삽입 위치를 가리킨다. 필사와 원문 등록·교정에는
선택한 펜 색을 옅게 쓰고, 느낀 점에는 연필색을 쓴다. 타이핑을 멈춰도 세로획의 크기와
농도를 유지한다. 확정된 한 글자가 잠깐 진해지는 효과는 `쓰기 도구 → 잉크 반응`에서 켜고 끌 수
있다. 한글 조합 중과 OS 동작 줄이기에서는 글자 효과를 쉬며, 입력 위치는 계속 표시한다.

## 표지도 함께 넘기는 책 · 2026-11-13

앞표지의 천 재질과 책등은 화면 가장자리까지 이어진다. 앞표지를 누르면 첫 쪽이 열리고,
왼쪽 위 ‘책장’을 누르면 책장으로 돌아간다. 오른쪽 가장자리를 왼쪽으로
끌면 왼쪽 책등을 축으로 앞표지가 열린다. 반대로 넘기면 앞표지가 닫힌다.

마지막 장에서 왼쪽으로 밀면 뒷표지가 오른쪽에서 올라와 종이를 덮는다.
닫히면 천으로 된 겉면이 보인다. 오른쪽으로 밀거나 ‘마지막 장 펼치기’를 누르면
마지막 쪽이 다시 펼쳐진다. ‘한 쪽 더’를 누르면 그 뒤에 새 쪽을 추가한다.
짧게 끌었다 놓으면 시작한 면으로 돌아오며, 넘김 효과 끄기와 OS 동작 줄이기를 따른다.

## 한 장을 들추고 한 권으로 묶기

읽는 동안 아래쪽 바깥 모서리를 끌면 종이가 말리면서 뒷면과 옆 장이 드러난다.
짧게 끌었다 놓으면 현재 쪽으로 돌아온다. 쓰는 동안에는 하단 쪽수 영역에서만
넘길 수 있다. 책으로 묶은 필사는 앞뒤에 쌓인 쪽 수를 양쪽 종이 단면으로 표시하고,
보관함 표지에서도 제본과 종이 단면이 보인다.

보관함의 책 상세에서 린넨 표지와 내지를 각각 선택한다. Aa에서도 현재 책의 내지를
고르거나 기본 종이로 돌릴 수 있다. 내지는 색과 결의 강도가 다르다. Aa의
‘종이 넘김 효과’와 ‘종이 넘김 소리’는 독립 설정이다. 소리는 기본으로 꺼져 있으며,
켰을 때 이동을 마친 뒤에만 실제 종이 넘김 녹음을 재생한다.

## 원문은 책에, 필사는 종이에 · 2026-11-11

`보관함 → 책 → 책 상세 → 원문`이나 쓰기 화면 하단 `원문`에서 구절을 여러 개
등록할 수 있다. 처음 하단 `원문`을 누르면 바로 등록 화면을 연다. 출처는 선택이다.
같은 책의 모든 필사와 쪽에서 사용하고, 책 없는 기록은 해당 기록에 저장한다.
원문 등록에서 ‘저장’은 원문을 보관하고, ‘저장하고 필사하기’는 밑글씨를 띄운
필사 쪽까지 연다. 저장한 원문에서도 ‘이 구절 필사하기’를 눌러 시작할 수 있다.
현재 쪽에 다른 글이 있으면 새 쪽을 쓴다. 앱을 다시 열거나 다른 쪽에 다녀와도
고른 구절과 입력을 이어갈 수 있다. 밑글씨는 미리보기로 표시되며 본문에는 직접
입력한 글만 들어간다.

종이를 펼치면 바로 쓴다. 입력한 단어 하나가 원문의 한 곳에만 일치해도 이어지는
한 줄을 옅은 밑글씨로 보여 준다. 단어 중간부터 맞거나 여러 곳에 일치하면 더 입력할
때까지 기다린다. 직접 입력한 글만 저장한다. 다른 구절로 옮길 때는 한 줄 띄우고,
쪽은 기존 쪽수 메뉴와 책장 넘기기로 이동한다.

하단 원문을 열면 현재 쪽에서 직접 고른 구절, 현재 필사에 연결된 구절, 마지막으로
읽은 구절 순서로 찾는다. 읽던 구절은 앱을 열어 둔 동안 책별로 기억하며, 책 없는
필사는 기록별로 기억한다. 처음이라면 목록을 연다. 원문 목록으로 돌아가면 방금
읽은 항목이 보이도록 이동한다.
패널의 `원문 등록`으로 추가할 수 있고, 패널을 닫으면 쓰던 줄과 커서로 돌아온다.
기존 기록과 줄에 붙인 원문·출처도 목록에서 볼 수 있다. ‘밑칠한 구절만 보기’는
느낀 점에 표시를 남겼거나 필사 본문의 밑칠와 일치하는 원문만 보여 준다.
필사한 쪽을 찾으면 ‘필사한 쪽 열기’로 해당 글줄에 이동한다.

원문 목록은 선택한 원문 쪽지에 구절 첫 두 줄과 출처를 보여 준다. 원문이 여러 개면
선택한 문장 구분표를 쪽지 사이에 둔다. 원문 패널은 책의 종이 색·결·제본과 쓰기
글꼴·펜 색을 사용하고, 선택한 구절에 밑칠의 농도와 색을 적용한다.

느낀 점은 원문에서 구절 아래에 적는다. 이미 적은 글을 누르면 같은 자리에서
고칠 수 있다. 한글 조합을 마친 입력은 자동 저장되며, 내용을 전부 지우면 메모도
지운다. 필사 종이에는 저장한 느낀 점만 손글씨로 보여 준다. 본문과 겹칠 때는
줄 여백에 작은 연필 표시를 남긴다.

원문 등록은 종이 쪽지부터 보여 준다. 쪽지에 직접 적거나 바로 아래의
`붙여넣기`를 사용한다. `사진에서 가져오기`에서 `책 한 페이지 인식`과
`문단 인식`을 고른다. 보관할 책과 출처는 아래 기록란에서 입력하고, 하단에
다른 앱에서 공유하는 방법과 저장을 둔다. [원문 등록 화면 기준](book-details-design.md#원문-등록-화면)
원문 패널 상단의 돋보기나 등록 화면의 ‘시·문장 검색’에서 찾는다.
‘작품 제목’은 한글 제목의 띄어쓰기가 달라도 찾고 일치하는 개별 작품을 먼저 보여 준다.
‘작가 이름’으로 위키문헌 작가 페이지를, ‘기억나는 구절’로 위키문헌과 위키인용집을 찾는다.
검색 결과 아래에서 네이버 검색으로 이어갈 수 있다. ‘원문 미리보기’가 표시된 작품은
줄바꿈을 유지해 읽고, 원하는 연 또는 전체를 출처와 함께 등록 화면에 담을 수 있다.
다른 자료는 외부 원문을 열고 ‘복사한 구절과 출처 넣기’를 사용한다. 저장은 등록 화면에서 한다.

설치형 앱과 웹에서 `카메라로 바로 읽기`를 고르면 카메라 화면에서 글자를 인식한다.
한 페이지는 감지한 종이 테두리를 표시하고 `이 페이지 사용`으로 확정하면 기울기를
보정한 인식 결과를 검수한다. 종이 테두리가 잡히기 어려우면 현재 화면을 읽을 수 있다.
문단은 화면에 표시된 문단을 눌러 그 순간의 화면을 확정한다. 시작·끝 단어를 고른 뒤
구절을 한 번 더 읽는다. 두 모드 모두 확정한 순간의 전체 카메라 화면 한 장을 보관한다.
파일이나 앨범의 사진으로도 등록할 수 있다.
한 페이지 인식은 전체를 원문 하나로 저장한다. 페이지 인식 결과에서 머리글과
쪽수를 빼거나 읽는 순서를 고칠 수 있다. 기본 필사 범위는 전체 페이지이며,
범위를 좁힐 때는 사진에서 시작 줄과 끝 줄을 누른다. 선택한 줄이 사진 위에 표시되고,
글 보기에서 줄 범위를 조절하거나 글을 직접 선택하면 해당 글자에 바로 밑칠이 보인다.
등록한 원문을 다시 열어 범위를 바꿀 수 있다.
문단 인식은 사진에서 문단을 고르고 시작 단어와 끝 단어를 눌러 구절을 좁힌다.
선택한 구절만 원문으로 저장하며 해당 영역을 다시 인식할 수 있다.
같은 사진에서 두 모드를 오갈 수 있다.
인식 결과에서 사진을 화면 높이에 맞춰 보여 준다. 결과와 교정 화면의
‘사진 크게 보기’에서 전체 화면으로 확대할 수 있다. 교정 화면에서 줄을 누르면
사진 속 해당 위치를 확대해 비교할 수 있다.
줄바꿈 정리는 결과를 미리 보여 준 뒤 적용한다.
두 사진 인식 모드 모두 가져온 원본 사진을 기기에 함께 보관한다. 원문에서
`원본 사진`을 누르면 확대해 볼 수 있다. 이 기기에 있는 사진은 전체 백업에도 담는다.
기기 간 동기화는 원문과 필사 범위를 전달한다. 다른 기기로 사진을 옮길 때는
백업에서 가져오기를 사용한다.
외부 공유로 받은 구절도 기존 책에 보관할 수 있다. URL만 전달되면 출처 칸에 넣고
사용자가 필사할 구절을 입력한다.

## 문장 구분표·압화 장식 · 2026-11-11

두 요소를 일반 앱에 기본 표시한다. `쓰기 도구 → 책의 디테일`에서 기존 일곱 요소와
같이 각각 모양·색·표시를 선택하고 하나씩 초기화할 수 있다.

- 문장 구분표: 같은 책 안의 필사 기록 사이에 세 점·짧은 선·작은 꽃을 선택해 표시한다.
  본문에 문자를 넣거나 쪽을 나누지 않는다.
- 압화 장식: 표지와 장서표의 아래쪽에 잎·들꽃·고사리를 놓는다. 오른쪽·왼쪽·가운데를
  선택하며 글씨와 편집 버튼의 영역을 확보한다. 장서표의 테두리와 별도로 숨길 수 있다.

## 손에 맞춰 넘기는 책

읽기 상태에서 종이를 좌우로 끌면 움직인 폭만큼 옆 장의 실제 글이 드러난다.
짧게 당겼다 놓거나 되돌리면 원래 장에 머무르고, 충분히 당기거나 의도적으로
휙 넘기면 한 장을 마저 넘긴다. 책에 묶인 기록은 책 전체에서 이어지고, 책에 묶지
않은 기록도 독립적으로 넘길 수 있다. 첫 장보다 앞에는 제목과 저자를 담은 표지가 있다.
표지에서 왼쪽으로 넘기거나 ‘책 펼치기’를 누르면 첫 장으로 돌아간다. 쪽수 목록에서도
표지를 선택할 수 있다. 표지는 쪽수에 포함되지 않으며 보던 첫 장의 글은 유지된다.

## 일곱 요소의 재질과 비례 다듬기

책갈피의 무광 직조·박음질과 끝 비례, 장서표의 인쇄 위계·이름 조작, 쪽지의 종이 결·클립/접힘과 테두리 없는 입력, 연필선 두께, 쪽수 문양, 제본 실 고리, 날짜인의 잉크 압인을 정리한다. 기존 모양/색 선택과 기록 데이터는 유지한다. 이후 추가한 세 요소도 같은 종이·천·잉크의 조형 규칙을 따른다.


## 점멸 커서 없는 종이 · 2026-11-10

본문 입력 위치는 글자 사이의 옅은 세로획으로 표시한다. 펜 반응 끄기와 OS 동작 줄이기 설정은 새 글자의 농도 효과에 적용한다.
한글 조합 표시·문자 입력·키보드 이동·탭 위치 지정·글 선택과 수정은 실제 입력기가
처리하며 본문·선택 영역·저장은 보존한다. 제목·원문 메모 등 보조 입력칸은 그대로다.
원문을 옅은 밑글씨처럼 채우는 필사 방식은 별도 제안 단계이며 이번 변경은 본문의
점멸 커서 숨김이다.

## 일반 화면에서 바로 사용

아홉 가지 스타일 요소와 설정은 일반 앱에 직접 적용한다. 모양·색 선택은 즉시 적용·저장한다.
앱 안의 예시 둘러보기와 비영구 데모 진입을 제거한다. 예전 `?demo=reference`·
`?demo=typeface` 링크도 같은 실제 저장소를 열며, 웹에서는 해당 데모 매개변수만
주소에서 정리한다. 기존 원문·책·페이지·도구 선택과 저장 실패 보호를 유지한다.
첫 실행에 합성 문장·책·이름·날짜를 사용자 기록으로 생성하지 않는다.

## 독서와 쓰기의 일곱 스타일 요소

2026-11-10 요청으로 책의 물성과 독서 흔적을 실제 Flutter 화면에 추가했다.

1. 포도빛 천 책갈피: 저장된 현재 글의 상단, 보관함의 현재 글·책 표지, 페이지 목록의 현재 쪽에 나타난다. 현재 위치를 표시하는 장식이다. 목차에서는 책마다 마지막으로 펼친 쪽의 기록을 표시한다.
2. 장서표: 보관함 → 책 → 책 선택에서 잉크 표식·이중 테두리·책 제목·편/쪽수·저자를 보여 준다. 주인의 이름이나 필명을 선택적으로 남기고 수정·비울 수 있다. 저자와 소유자의 이름을 구분한다.
3. 종이쪽지: 원문 메모의 접힌 표시와 편집 대화상자를 밝은 미색 쪽지, 얕은 한쪽 그림자로 표현한다. 원문 본문은 실제 입력 위젯이다.
4. 밑칠: 구절을 선택하고 ‘밑칠하기’를 누르면 글씨 뒤에 옅은 황토빛을 남긴다. 밑칠 안의 구절을 다시 선택해 ‘밑칠 지우기’를 누르면 해당 부분만 지운다. 책 꾸미기에서 농도와 색을 고른다. 입력 중에는 선택·본문·composing을 되쓰지 않는다. 새로 삽입하거나 대체한 글자에는 표시를 자동 적용하지 않고, 남아 있는 글자의 표시는 이동한다.
5. 판면 장식: 실제 페이지 이동·추가 조작부의 쪽수 양옆에 작은 선과 점을 둔다. 좁은 폭·큰 시스템 글씨에서는 장식을 줄여 조작부와 입력 공간을 확보한다.
6. 제본 흔적: 기존 천 표지에 책등의 가는 눌림선을 더하고, 종이의 위아래 안쪽에는 짧은 직조 헤드밴드를 둔다. 기존 왼쪽 안쪽 음영과 함께 정적으로 표시한다.
7. 날짜인: 새로 보관한 페이지의 기록 시작일을 보관함과 더 보기에서 작은 브라운 도장으로 표시한다. 이미 저장된 과거 페이지의 날짜는 추정하지 않는다. 합성 예시 화면의 날짜·이름·연필 표시는 예시 데이터다.

장식은 입력과 터치를 가로채지 않는다. 책 없는 기록, 바로 쓰기, 종이·펜·글꼴의 독립 선택과 기존 개발 서체의 표기를 유지한다. 쇼핑 기능은 추가하지 않는다.

각 요소는 쓰기 도구 → 책의 디테일에서 표시 여부, 세 가지 모양, 네 가지 색을 따로 선택한다. 숨겨도 이름·원문·구절 표시·날짜 데이터는 보존한다. ‘이 요소만 기본으로’는 선택한 요소만 복원한다. 색·치수·상태·동작·저장·조합 규칙과 완료 기준은 [아홉 가지 요소 독립 설계](book-details-design.md)에 정의한다.



## 페이지를 넘기며 쓰기 · 2026-11-10

하단에는 실제 책의 쪽수처럼 현재 페이지 번호만 작게 둔다. 이전·다음 화살표와
페이지 추가 버튼·전체 쪽수 분수 표시는 제거한다. 저장 상태는 쪽수 아래에 작게
표시하고 저장 실패는 기존 배너와 재시도로 명확히 알린다. 도구와 더 보기는 유지한다.

읽는 상태에서는 종이 위를 좌우로 쓸어 넘긴다. 왼쪽은 다음 쪽, 오른쪽은 이전
쪽이다. 마지막 쪽에서 왼쪽으로 넘기면 같은 필사에 새 빈 종이가 생긴다. 첫 쪽에서
오른쪽으로 넘기면 그대로 머문다. 짧은 손 떨림·세로 스크롤은 페이지를 만들지 않는다.
마우스로 본문을 드래그하면 글을 선택하고, 쪽수 영역은 마우스 드래그도 지원한다.

글을 쓰는 동안 본문을 길게 누른 뒤 끌어서 밑칠할 수 있다.
이때도 하단 쪽수 영역을 좌우로 쓸어 넘길 수 있다. 쪽수를 누르면 본문이 담긴
종이 미리보기가 열려 페이지를 고를 수 있고, 보조 화면의 ‘한 쪽 더’도 사용할 수 있다.
상단 브랜드·본문·하단 도구를 포함한 화면 전체가 한 장으로 넘어가는 연출을 유지한다.

첫 빈 종이에서 명시적으로 다음 쪽으로 넘기면 첫 쪽과 둘째 쪽을 저장한다.
앱을 열거나 포커스만 주는 것으로 빈 기록을 저장하지 않는다. 자동 페이지 분할은
하지 않는다. 각 쪽의 본문·선택 영역·스크롤은 이동과 재실행 때 복원한다.

새 페이지는 전환 중에도 바로 입력할 수 있다. 한글 조합 중에는 이동·추가를 막고,
저장 실패 시 현재 글을 유지하며 재시도 후 이동한다. OS 동작 줄이기 설정에서는
즉시 전환한다. 넘김 소리는 후속 범위다.

내 취향으로 쓰고, 한 권으로 남기는 즐거움.

## 글씨 가독성

쓰는 인간체 0.007의 실제 획을 두껍게 하고 본문·제목·메뉴의 표시 크기를 20% 키운다.
일반 조작/안내 문구는 최소 14px, 기본 본문은 약 27.6px로 표시한다. 시스템 글씨 확대는
이보다 큰 기준에 그대로 적용한다. 작은 표지 썸네일의 장식 글씨는 표지 비율을 유지하며
같은 책의 제목은 옆의 실제 목록 글씨로 읽을 수 있다. 날짜 안내는 좁으면 줄을 바꾼다.
입력·선택·composing을 다시 설정하지 않는다.

## 현재 UX · 바로 쓰는 종이

2026-11-10 사용자 피드백을 반영한 현재 기준이다. 앱을 열면 마지막 글 또는 빈 종이가 바로 보인다. 책 이름·종이·펜·글꼴 선택을 입력의 선행 조건으로 두지 않는다. 한 번 눌러 입력하고 자동 저장한다. 빈 종이를 열거나 포커스만 주는 것으로는 기록을 만들지 않는다. 첫 글자 또는 원문 메모가 생기면 실제 기록을 저장한다.

첫 화면은 보관함, 새 종이, 본문, 작은 도구/저장 표시로 구성한다. 원문은 하단 왼쪽, 페이지 목록은 가운데 쪽수로 연다. 쓰기 도구에서 쓰기 설정과 책에 넣기·기록 보관을 열며 동기화가 가능한 환경에서는 기기 동기화도 제공한다. 책장/책 상세를 거쳐야 쓰는 흐름과 다섯 개 하단 메뉴는 현재 UX에서 사용하지 않는다. 책 없는 기록을 먼저 쓰고 이후 책으로 묶어도 같은 본문·페이지·선택 영역을 유지한다. 상단 ＋에는 책 안에서 ‘이 책에 한 쪽 추가’, 책 밖에서 ‘새 종이’ 접근성 이름을 붙인다. 하단 ‘쓰기 도구’에서는 종이·펜·글꼴을 바꿀 수 있다. 두 버튼은 최소 48px 터치 영역을 제공한다.

최신 종이 시안을 실제 작성 화면에 반영한다. 브랜드 잉크는 #70472F, 기본 종이는 #F7F2E8, 기본 본문은 #302C27이다. 작성 화면 상단의 제목을 양옆 버튼과 같은 높이에 두고, 화면의 왼쪽에는 얕은 책 안쪽 음영을 둔다. 작성지·상단·하단을 같은 종이 면으로 연결하며 본문을 별도 카드에 넣지 않는다. 종이 결은 은은하게 유지한다. 상단에는 보관함·브랜드·새 종이(＋), 하단은 왼쪽 원문, 가운데 쪽수와 저장 상태, 오른쪽 쓰기 도구 순서로 둔다. 키보드가 올라오면 제목과 본문 위쪽 여백을 유지하고 키보드가 가리는 아래쪽만 조정한다. 책에 묶인 쪽에서는 상단 제목에 책 이름이 나온다. 책 상세의 연필 버튼으로 이름을 바꾼다. 빈 종이의 본문은 비어 있다. 본문과 제목·메뉴·도구·대화상자의 기본 글꼴은 실제 쓰는 인간체다. 기존 페이지에도 한 번 적용하며 이후 사용자가 고른 다른 본문 글꼴은 유지한다. 종이·표식은 이미지 소재, 본문·조작부는 접근성과 입력을 유지하는 실제 Flutter 위젯이다. 입력 중 작은 펜 반응은 유지한다.

## 제품 원칙

타이핑 전용 필사 앱이다. 단정한 화면에 실제 종이의 재료감과 편안한 한글 본문 활자를 표현한다. 종이·펜·글꼴은 독립적으로 선택하며, 펜에 작은 반응과 글쓰기 소리, 페이지 넘김 소리를 단계적으로 붙인다. 소리와 움직임은 끌 수 있게 한다. 한글 입력과 기록 보존이 모든 연출보다 우선한다.

책 → 필사 기록 → 페이지 구조. 책 없이 먼저 쓰고, 나중에 기존 책에 묶을 수 있다. 빈 서재에서 시작하며 샘플 문장을 사용자의 기록으로 자동 생성하지 않는다. 초기 앱에는 쇼핑·결제·오프라인 샵 메뉴가 없다. 오프라인 샵은 장기 브랜드 계획이다. ‘쓰는 인간체’는 현대 한글 11,172자·자모·영문·숫자를 지원하는 개발 중 선택지다. 기본 글꼴은 쓰는 인간체이며 지원 범위 밖에는 SIL OFL의 번들 나눔명조 등을 사용한다. 문자 지원 범위와 출시 완성도는 구분하며, 최종 광학·실기기 검수 전에는 완성 서체로 표시하지 않는다.

## 구현 순서

사용자의 서체 적용 요청에 따라 Aa → 글꼴에 ‘쓰는 인간체 · 개발 중’을 추가했다.
선택하면 본문과 브랜드 제목에 실제 개발 TTF를 사용하고, 미지원 글자는
나눔명조 등으로 보완한다. 전체 현대 한글을 지원하지만 개발 중임을 도구 화면에 명시한다.
기존 기록은 쓰는 인간체로 한 번 전환한다. 본문·선택·스크롤·종이·펜을 보존하며 이후 사용자가 선택한 다른 글꼴은 유지한다.

이전 데모 주소도 일반 앱으로 열린다. 실제 기록에 아홉 가지 요소와 현재 기본 서체를 바로 적용한다.

1. 책 생성 → 필사 작성 → 실제 로컬 저장 → 재실행 시 본문과 마지막 위치 복원. 종이 질감과 나눔명조를 이 단계부터 적용한다.
2. 종이·펜·글꼴을 독립적으로 선택. 폰트와 종이 변경 시 본문·커서를 보존한다.
3. 여러 필사의 제목·순서·묶기 관리. 현재는 필사 추가, 기록 선택, 책 없는 기록 묶기만 가능하다.
4. 버전이 있는 백업·복원. 복원 전 검증과 기존 자료 보호. 웹의 기기 간 동기화는 docs/sync.md에 정의한다.
5. 펜의 작은 반응과 소리. IME 조합 중 반응으로 입력을 방해하지 않는다. 실제 폰에서 지연을 확인한다.

현재 범위에서는 페이지를 사용자가 직접 추가한다. 글을 자동 분할하거나 입력 중 재배치하지 않는다. 삭제·공유·쇼핑은 구현하지 않았다. 웹에서는 같은 ChatGPT 계정의 PC·모바일 기록을 동기화한다. 설치형 앱 계정 인증은 아직 연결하지 않았다.

## 참조 이미지 적용 · 이전 디자인 방향

아래는 초기 참조 이미지 적용 기록이다. 현재 화면과 진입 흐름은 위의 '현재 UX · 바로 쓰는 종이' 기준을 따른다.

첨부 이미지의 책장, 책 상세, 필사, 종이 선택, 글꼴 선택을 실제 Flutter 화면에 반영한다. 종이빛 #F7F2E8, 잉크 브라운 #5B4636, 책표지 그린 #4E5A42, 고요한 블루 #5B6F8E, 포도레드 #7A4A4A를 기준으로 한다. 개발 중인 쓰는 인간체는 잠금 상태로 보여 주고 실제 사용 가능한 나눔명조/나눔고딕만 선택할 수 있다. 쇼핑·오프라인 샵 메뉴는 추가하지 않는다.

종이·펜·글꼴의 독립 선택, 줄 가이드, 원문 메모, 즐겨찾기를 제공한다. 가는 세로 커서가 실제 입력 위치를 표시하고, 확정된 글자는 잠깐 짙어진다. 한글 조합 중에는 위치만 표시하고 선택 영역을 펼치면 커서를 숨긴다. 글자 반응은 쓰기 도구에서 끌 수 있고 OS 동작 줄이기 설정을 따른다. 백업·복원과 쓰기·종이 넘김 소리는 후속 범위다.

## 기기 간 이어 쓰기

로컬 저장을 유지하면서 같은 계정의 PC·모바일 브라우저에서 책·필사·페이지·마지막 위치·도구 설정을 동기화한다. 오프라인 수정은 재연결 시 반영하고, 서로 다른 수정본은 별도의 필사로 보존한다. 예시 책장은 동기화하지 않는다. 기존 익명 기기 기록은 사용자가 명시적으로 가져온다. 현재 설치형 앱은 로컬 저장만 제공한다.
