# 쓰는 인간

## 종이에 남는 잉크

글씨가 써지는 위치는 작은 잉크 점으로 표시한다. 점은 즉시 입력 위치를 따르고,
확정된 한 글자에는 잉크가 잠깐 더 진하게 보였다가 가라앉는다. 반응은 420ms 안에
끝나며 점의 농도도 낮아진다. 한글 조합 중에는 농도 효과를 쉬고, 본문은 즉시 표시한다.
`Aa → 잉크 반응`에서 효과를 켜고 끌 수 있다. OS 동작 줄이기 설정도 따른다.

## 표지도 함께 넘기는 책 · 2026-11-11

앞표지와 뒷표지는 책등을 축으로 회전하고, 기울기에 따라 그림자와 빛이 변한다.
드래그 도중 놓으면 표지도 원래 자리로 돌아온다. 버튼이나 쪽수 목록에서 표지로
이동할 때도 같은 회전을 사용한다. 넘김 효과 끄기와 OS 동작 줄이기를 따른다.

저장된 기록의 마지막 장을 넘기면 뒷표지가 닫힌다. 뒷표지를 오른쪽으로 넘기거나
‘마지막 장 펼치기’를 누르면 마지막 글로 돌아온다. ‘한 쪽 더’를 누르면 그 뒤에
새 쪽을 추가한다. 첫 빈 종이에서 다음 쪽을 만드는 동작은 이어서 사용할 수 있다.
표지를 보는 동안에도 마지막 실제 쪽의 글·선택 영역·스크롤을 보존한다.

## 한 장을 들추고 한 권으로 묶기

읽는 동안 아래쪽 바깥 모서리를 끌면 종이가 말리면서 뒷면과 옆 장이 드러난다.
짧게 끌었다 놓으면 현재 쪽으로 돌아온다. 쓰는 동안에는 하단 쪽수 영역에서만
넘길 수 있다. 책으로 묶은 필사는 앞뒤에 쌓인 쪽 수를 양쪽 종이 단면으로 표시하고,
보관함 표지에서도 제본과 종이 단면이 보인다.

보관함의 책 상세에서 린넨 표지와 내지를 각각 선택한다. Aa에서도 현재 책의 내지를
고르거나 기본 종이로 돌릴 수 있다. 내지는 색과 결의 강도가 다르다. Aa의
‘종이 넘김 효과’와 ‘종이 넘김 소리’는 독립 설정이다. 소리는 기본으로 꺼져 있으며,
켰을 때 이동을 마친 뒤에만 실제 종이 넘김 녹음을 재생한다.

## 원문 놓기 · 2026-11-11

종이 상단에서 `따라 쓰기`를 누른다. 구절을 붙여넣거나 바로 입력한 뒤
`따라 쓰기` 버튼 하나로 원문을 저장하고 밑글씨를 펼친다.
쓰는 화면의 `원문 보기`를 누르면 종이 위쪽에 읽을 문단이 펼쳐진다. 종이 아래의
본문을 누르면 쓸 수 있다. 원문의 줄바꿈을 살리고, 본문에 글이 있는 상태에서
입력할 때는 원문 잉크를 조금 옅게 표시한다. 긴 문단은 원문 안에서 스크롤한다.
빈 줄로 구분된 문단이 여러 개면 이전·다음 화살표로 읽을 문단을 고른다.
원문을 넘겨도 쓰던 자리는 그대로이며, 앱을 다시 열면 첫 문단부터 표시한다.
원문을 고치려면 원문 위의 연필 아이콘을 누른다.

`책 사진`은 설치형 앱에서 촬영·앨범, 웹에서 이미지 파일을 받는다.
사진은 기기 안에서 읽고, 원하는 문단을 고른 뒤 오탈자를 직접 고칠 수 있다.
다른 앱에서 선택한 글을 공유하면 Android는 앱으로 이어지고, iOS는 공유 창에서
저장한 뒤 앱으로 돌아오면 확인할 수 있다. 확인한 공유 원문은 책 없는 새 필사
기록으로 시작한다.

읽을 문단의 `따라 쓰기`를 누르면 원문이 본문 입력 위치 뒤에 옅은 밑글씨로
나타난다. 쓴 글은 진하게 남고, 원문과 다르게 쓰면 밑글씨가 사라진다.
이전·다음 문단은 쓰는 사람이 넘긴다. `원문 보기`로 문단을 다시 펼치고
`따라 쓰기`로 같은 자리의 밑글씨를 되살릴 수 있다. 앱에 저장되는 본문은
입력한 글이며, 밑글씨 표시 상태는 화면을 열어 둔 동안만 이어진다.

## 색인 탭·문장 구분표·압화 장식 · 2026-11-11

세 요소를 일반 앱에 기본 표시한다. `Aa → 책의 디테일`에서 기존 일곱 요소와
같이 각각 모양·색·표시를 선택하고 하나씩 초기화할 수 있다.

- 색인 탭: 보관함의 ‘책’ 목록 위와 책 안쪽에 가로로 놓인다. 누르면 대상 책이 열리고,
  책 표지의 옆면에도 같은 탭의 재질을 표시한다. 책 안쪽 ‘색인 이름’에서 책마다 이름을
  붙일 수 있다. 비우면 책 제목이 표시된다. 탭을 숨겨도 이름은 유지한다.
- 문장 구분표: 같은 책 안의 필사 기록 사이에 세 점·짧은 선·작은 꽃을 선택해 표시한다.
  본문에 문자를 넣거나 쪽을 나누지 않는다.
- 압화 장식: 표지와 장서표의 아래쪽에 잎·들꽃·고사리를 놓는다. 오른쪽·왼쪽·가운데를
  선택하며 글씨와 편집 버튼의 영역을 확보한다. 장서표의 테두리와 별도로 숨길 수 있다.

## 손에 맞춰 넘기는 책

읽기 상태에서 종이를 좌우로 끌면 움직인 폭만큼 옆 장의 실제 글이 드러난다.
짧게 당겼다 놓거나 되돌리면 원래 장에 머무르고, 충분히 당기거나 의도적으로
휙 넘기면 한 장을 마저 넘긴다. 책에 묶인 기록은 책 전체에서 이어지고, 책에 묶지
않은 기록도 독립적으로 넘길 수 있다. 첫 장보다 앞에는 제목과 저자를 담은 표지가 있다.
표지에서 왼쪽으로 넘기거나 ‘책 펼치기’를 누르면 첫 장으로 돌아간다. 쪽수 목록에서도
표지를 선택할 수 있다. 표지는 쪽수에 포함되지 않으며 보던 첫 장의 글은 유지된다.

## 일곱 요소의 재질과 비례 다듬기

책갈피의 무광 직조·박음질과 끝 비례, 장서표의 인쇄 위계·이름 조작, 쪽지의 종이 결·클립/접힘과 테두리 없는 입력, 연필선 두께, 쪽수 문양, 제본 실 고리, 날짜인의 잉크 압인을 정리한다. 기존 모양/색 선택과 기록 데이터는 유지한다. 이후 추가한 세 요소도 같은 종이·천·잉크의 조형 규칙을 따른다.


## 점멸 커서 없는 종이 · 2026-11-10

본문의 깜빡이는 세로 입력 커서를 숨긴다. 현재 위치는 기존 선택한 펜이 글자
끝을 따라가는 반응으로 표현한다. 펜 반응 끄기와 OS 동작 줄이기 설정은 유지한다.
한글 조합 표시·문자 입력·키보드 이동·탭 위치 지정·글 선택과 수정은 실제 입력기가
처리하며 본문·선택 영역·저장은 보존한다. 제목·원문 메모 등 보조 입력칸은 그대로다.
원문을 옅은 밑글씨처럼 채우는 필사 방식은 별도 제안 단계이며 이번 변경은 본문의
점멸 커서 숨김이다.

## 일반 화면에서 바로 사용

열 가지 스타일 요소와 설정은 일반 앱에 직접 적용한다. 모양·색 선택은 즉시 적용·저장한다.
앱 안의 예시 둘러보기와 비영구 데모 진입을 제거한다. 예전 `?demo=reference`·
`?demo=typeface` 링크도 같은 실제 저장소를 열며, 웹에서는 해당 데모 매개변수만
주소에서 정리한다. 기존 원문·책·페이지·도구 선택과 저장 실패 보호를 유지한다.
첫 실행에 합성 문장·책·이름·날짜를 사용자 기록으로 생성하지 않는다.

## 독서와 쓰기의 일곱 스타일 요소

2026-11-10 요청으로 책의 물성과 독서 흔적을 실제 Flutter 화면에 추가했다.

1. 포도빛 천 책갈피: 저장된 현재 글의 상단, 보관함의 현재 글·책 표지, 페이지 목록의 현재 쪽에 나타난다. 실제 활성 위치를 표시하는 장식이며 별도의 책갈피 버튼이나 책별 위치 저장을 뜻하지 않는다.
2. 장서표: 보관함 → 책 → 책 선택에서 잉크 표식·이중 테두리·책 제목·편/쪽수·저자를 보여 준다. 주인의 이름이나 필명을 선택적으로 남기고 수정·비울 수 있다. 저자와 소유자의 이름을 구분한다.
3. 종이쪽지: 원문 메모의 접힌 표시와 편집 대화상자를 밝은 미색 쪽지, 얕은 한쪽 그림자로 표현한다. 원문 본문은 실제 입력 위젯이다.
4. 연필 흔적: 본문에서 구절을 선택하고 선택 메뉴의 ‘연필 표시’를 누르면 가는 회색 밑줄을 남긴다. 표시 안의 구절을 다시 선택하면 해당 부분을 지운다. 입력 중에는 선택·본문·composing을 되쓰지 않는다. 새로 삽입하거나 대체한 글자에는 표시를 자동 적용하지 않고, 남아 있는 글자의 표시는 이동한다.
5. 판면 장식: 실제 페이지 이동·추가 조작부의 쪽수 양옆에 작은 선과 점을 둔다. 좁은 폭·큰 시스템 글씨에서는 장식을 줄여 조작부와 입력 공간을 확보한다.
6. 제본 흔적: 기존 천 표지에 책등의 가는 눌림선을 더하고, 종이의 위아래 안쪽에는 짧은 직조 헤드밴드를 둔다. 기존 왼쪽 안쪽 음영과 함께 정적으로 표시한다.
7. 날짜인: 새로 보관한 페이지의 기록 시작일을 보관함과 더 보기에서 작은 브라운 도장으로 표시한다. 이미 저장된 과거 페이지의 날짜는 추정하지 않는다. 합성 예시 화면의 날짜·이름·연필 표시는 예시 데이터다.

장식은 입력과 터치를 가로채지 않는다. 책 없는 기록, 바로 쓰기, 종이·펜·글꼴의 독립 선택과 기존 개발 서체의 표기를 유지한다. 쇼핑 기능은 추가하지 않는다.

각 요소는 Aa → 책의 디테일에서 표시 여부, 세 가지 모양, 네 가지 색을 따로 선택한다. 숨겨도 이름·원문·구절 표시·날짜 데이터는 보존한다. ‘이 요소만 기본으로’는 선택한 요소만 복원한다. 색·치수·상태·동작·저장·조합 규칙과 완료 기준은 [열 가지 요소 독립 설계](book-details-design.md)에 정의한다.



## 페이지를 넘기며 쓰기 · 2026-11-10

하단에는 실제 책의 쪽수처럼 현재 페이지 번호만 작게 둔다. 이전·다음 화살표와
페이지 추가 버튼·전체 쪽수 분수 표시는 제거한다. 저장 상태는 쪽수 아래에 작게
표시하고 저장 실패는 기존 배너와 재시도로 명확히 알린다. 도구와 더 보기는 유지한다.

읽는 상태에서는 종이 위를 좌우로 쓸어 넘긴다. 왼쪽은 다음 쪽, 오른쪽은 이전
쪽이다. 마지막 쪽에서 왼쪽으로 넘기면 같은 필사에 새 빈 종이가 생긴다. 첫 쪽에서
오른쪽으로 넘기면 그대로 머문다. 짧은 손 떨림·세로 스크롤은 페이지를 만들지 않는다.
마우스로 본문을 드래그하면 글을 선택하고, 쪽수 영역은 마우스 드래그도 지원한다.

글을 쓰는 동안에는 본문 드래그와 길게 눌러 선택하기를 기존 편집기에 맡긴다.
이때도 하단 쪽수 영역을 좌우로 쓸어 넘길 수 있다. 쪽수를 누르면 본문이 담긴
종이 미리보기가 열려 페이지를 고를 수 있고, 보조 화면의 ‘한 쪽 더’도 사용할 수 있다.
상단 브랜드·본문·하단 도구를 포함한 화면 전체가 한 장으로 넘어가는 연출을 유지한다.

첫 빈 종이에서 명시적으로 다음 쪽으로 넘기면 첫 쪽과 둘째 쪽을 저장한다.
앱을 열거나 포커스만 주는 것으로 빈 기록을 저장하지 않는다. 자동 페이지 분할은
하지 않는다. 각 쪽의 본문·선택 영역·스크롤은 이동과 재실행 때 복원한다.

새 페이지는 전환 중에도 바로 입력할 수 있다. 한글 조합 중에는 이동·추가를 막고,
저장 실패 시 현재 글을 유지하며 재시도 후 이동한다. OS 동작 줄이기 설정에서는
즉시 전환한다. 넘김 소리는 후속 범위다.

내 취향으로 쓰고, 한 권으로 남기는 즐거움.

## 글씨 가독성

쓰는 인간체 0.007의 실제 획을 두껍게 하고 본문·제목·메뉴의 표시 크기를 20% 키운다.
일반 조작/안내 문구는 최소 14px, 기본 본문은 약 27.6px로 표시한다. 시스템 글씨 확대는
이보다 큰 기준에 그대로 적용한다. 작은 표지 썸네일의 장식 글씨는 표지 비율을 유지하며
같은 책의 제목은 옆의 실제 목록 글씨로 읽을 수 있다. 날짜 안내는 좁으면 줄을 바꾼다.
입력·선택·composing을 다시 설정하지 않는다.

## 현재 UX · 바로 쓰는 종이

2026-11-10 사용자 피드백을 반영한 현재 기준이다. 앱을 열면 마지막 글 또는 빈 종이가 바로 보인다. 책 이름·종이·펜·글꼴 선택을 입력의 선행 조건으로 두지 않는다. 한 번 눌러 입력하고 자동 저장한다. 빈 종이를 열거나 포커스만 주는 것으로는 기록을 만들지 않는다. 첫 글자 또는 원문 메모가 생기면 실제 기록을 저장한다.

첫 화면은 보관함, 새 종이, 본문, 작은 도구/저장 표시로 구성한다. 원문·책으로 묶기·페이지·동기화는 보조 시트에서 연다. 책장/책 상세를 거쳐야 쓰는 흐름과 다섯 개 하단 메뉴는 현재 UX에서 사용하지 않는다. 책 없는 기록을 먼저 쓰고 이후 책으로 묶어도 같은 본문·페이지·선택 영역을 유지한다. 상단 ＋와 하단 Aa는 각각 새 종이·쓰기 도구의 접근성 이름과 48px 이상의 터치 영역을 제공한다.

최신 종이 시안을 실제 작성 화면에 반영한다. 브랜드 잉크는 #70472F, 기본 종이는 #F7F2E8, 기본 본문은 #302C27이다. 자연스럽게 번진 작은 잉크 표식을 브랜드 이름 위에 두고, 화면의 왼쪽에는 얕은 책 안쪽 음영을 둔다. 작성지·상단·하단을 같은 종이 면으로 연결하며 본문을 별도 카드에 넣지 않는다. 종이 결은 은은하게 유지한다. 상단에는 보관함·브랜드·새 종이(＋), 하단에는 Aa·저장 상태·더 보기 또는 완료를 둔다. 입력 중 키보드가 올라오면 여백을 줄인다. 책 이름은 브랜드 아래 작은 문맥 표시로 구분한다. 본문과 제목·메뉴·도구·대화상자의 기본 글꼴은 실제 쓰는 인간체다. 기존 페이지에도 한 번 적용하며 이후 사용자가 고른 다른 본문 글꼴은 유지한다. 종이·표식은 이미지 소재, 본문·조작부는 접근성과 입력을 유지하는 실제 Flutter 위젯이다. 입력 중 작은 펜 반응은 유지한다.

## 제품 원칙

타이핑 전용 필사 앱이다. 단정한 화면에 실제 종이의 재료감과 편안한 한글 본문 활자를 표현한다. 종이·펜·글꼴은 독립적으로 선택하며, 펜에 작은 반응과 글쓰기 소리, 페이지 넘김 소리를 단계적으로 붙인다. 소리와 움직임은 끌 수 있게 한다. 한글 입력과 기록 보존이 모든 연출보다 우선한다.

책 → 필사 기록 → 페이지 구조. 책 없이 먼저 쓰고, 나중에 기존 책에 묶을 수 있다. 빈 서재에서 시작하며 샘플 문장을 사용자의 기록으로 자동 생성하지 않는다. 초기 앱에는 쇼핑·결제·오프라인 샵 메뉴가 없다. 오프라인 샵은 장기 브랜드 계획이다. ‘쓰는 인간체’는 현대 한글 11,172자·자모·영문·숫자를 지원하는 개발 중 선택지다. 기본 글꼴은 쓰는 인간체이며 지원 범위 밖에는 SIL OFL의 번들 나눔명조 등을 사용한다. 문자 지원 범위와 출시 완성도는 구분하며, 최종 광학·실기기 검수 전에는 완성 서체로 표시하지 않는다.

## 구현 순서

사용자의 서체 적용 요청에 따라 Aa → 글꼴에 ‘쓰는 인간체 · 개발 중’을 추가했다.
선택하면 본문과 브랜드 제목에 실제 개발 TTF를 사용하고, 미지원 글자는
나눔명조 등으로 보완한다. 전체 현대 한글을 지원하지만 개발 중임을 도구 화면에 명시한다.
기존 기록은 쓰는 인간체로 한 번 전환한다. 본문·선택·스크롤·종이·펜을 보존하며 이후 사용자가 선택한 다른 글꼴은 유지한다.

이전 데모 주소도 일반 앱으로 열린다. 실제 기록에 열 가지 요소와 현재 기본 서체를 바로 적용한다.

1. 책 생성 → 필사 작성 → 실제 로컬 저장 → 재실행 시 본문과 마지막 위치 복원. 종이 질감과 나눔명조를 이 단계부터 적용한다.
2. 종이·펜·글꼴을 독립적으로 선택. 폰트와 종이 변경 시 본문·커서를 보존한다.
3. 여러 필사의 제목·순서·묶기 관리. 현재는 필사 추가, 기록 선택, 책 없는 기록 묶기만 가능하다.
4. 버전이 있는 백업·복원. 복원 전 검증과 기존 자료 보호. 웹의 기기 간 동기화는 docs/sync.md에 정의한다.
5. 펜의 작은 반응과 소리. IME 조합 중 반응으로 입력을 방해하지 않는다. 실제 폰에서 지연을 확인한다.

현재 범위에서는 페이지를 사용자가 직접 추가한다. 글을 자동 분할하거나 입력 중 재배치하지 않는다. 삭제·공유·쇼핑은 구현하지 않았다. 웹에서는 같은 ChatGPT 계정의 PC·모바일 기록을 동기화한다. 설치형 앱 계정 인증은 아직 연결하지 않았다.

## 참조 이미지 적용 · 이전 디자인 방향

아래는 초기 참조 이미지 적용 기록이다. 현재 화면과 진입 흐름은 위의 '현재 UX · 바로 쓰는 종이' 기준을 따른다.

첨부 이미지의 책장, 책 상세, 필사, 종이 선택, 글꼴 선택을 실제 Flutter 화면에 반영한다. 종이빛 #F7F2E8, 잉크 브라운 #5B4636, 책표지 그린 #4E5A42, 고요한 블루 #5B6F8E, 포도레드 #7A4A4A를 기준으로 한다. 개발 중인 쓰는 인간체는 잠금 상태로 보여 주고 실제 사용 가능한 나눔명조/나눔고딕만 선택할 수 있다. 쇼핑·오프라인 샵 메뉴는 추가하지 않는다.

종이·펜·글꼴의 독립 선택, 줄 가이드, 원문 메모, 즐겨찾기를 제공한다. 펜촉이 실제 커서 위치를 따라 움직이고 확정된 입력에 짧게 반응한다. 한글 조합 중에는 위치만 표시하고 흔들림·보간을 멈춘다. 선택 영역을 펼치면 펜을 숨긴다. 펜 움직임은 쓰기 도구 → 펜에서 끌 수 있고 OS 동작 줄이기 설정을 따른다. 백업·복원과 쓰기·종이 넘김 소리는 후속 범위다.

## 기기 간 이어 쓰기

로컬 저장을 유지하면서 같은 계정의 PC·모바일 브라우저에서 책·필사·페이지·마지막 위치·도구 설정을 동기화한다. 오프라인 수정은 재연결 시 반영하고, 서로 다른 수정본은 별도의 필사로 보존한다. 예시 책장은 동기화하지 않는다. 기존 익명 기기 기록은 사용자가 명시적으로 가져온다. 현재 설치형 앱은 로컬 저장만 제공한다.
