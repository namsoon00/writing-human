# 쓰는 인간

## 브랜드 컨셉과 룩앤필

‘내 취향으로 쓰고, 한 권으로 남기는 즐거움’을 따뜻한 서재의 종이와 잉크로
표현한다. 앱을 열면 쓰던 종이가, 글을 모으면 내가 고른 천 표지의 책이 보인다.
새 화면도 종이의 여백·인쇄 위계·잉크색·책의 재질을 함께 사용한다.

- **글과 종이**. 필사면은 상단부터 하단까지 한 면으로 이어진다. 쪽에는 내가 쓴
  문장을 가장 크게 두고, 조작부는 가장자리에 모은다. 종이 결은 글 뒤에서 은은하다.
- **제목과 잉크**. 쓰는 인간체, 먹갈색 제목, 작은 잉크 번짐 표식이 화면을 연결한다.
  제목과 닫기 아래의 가는 인쇄선은 책 주변 화면의 첫머리를 구분한다.
- **도구와 선택**. 쓰기 도구는 위쪽에서 펜·형광펜·지우개의 모양과 이름으로
  고르고 현재 도구 하나에만 체크를 표시한다. 지우개는 기존 밑칠만 지운다.
  글꼴은 각 글꼴로 찍은 견본, 잉크는 종이에 번진 색으로 보여 준다.
  종이는 설정과 책 꾸미기에서 같은 견본과 이름으로 고른다.
- **책과 원문**. 책장은 천 표지와 선반, 목차는 제목과 쪽수의 인쇄 배치를 쓴다.
  원문은 쪽지와 출처로, 본문 견본은 고른 종이와 잉크로 보여 준다.
- **움직임과 읽기**. 장식보다 글의 가독성과 손의 조작이 먼저다. 터치 영역은
  48px 이상 확보하고 큰 시스템 글씨에서는 줄을 바꾸거나 세로로 배치한다.
  저장 실패와 다음 행동은 화면 문구 규칙에 맞춰 명확하게 표시한다.

새 화면을 검토할 때 위 기준으로 제목·본문·조작부·선택 상태를 함께 확인한다.
고른 종이 색은 쓰는 쪽과 본문 견본에 적용하고, 원문 화면에는 공통 미색을 사용한다.

## 화면 용어

| 용어 | 뜻과 쓰는 곳 |
| --- | --- |
| 책 | 책장에서 여는 내 책. 글과 담아 둔 원문을 모으고, 표지·내지·장서표를 가진다. 연습장도 한 권의 책이다. |
| 글 | 내가 직접 쓴 한 편. 필사와 자유롭게 쓴 글 모두 ‘내 글’에서 찾는다. 책 없이 시작할 수 있다. |
| 쪽 | 글이 놓이는 종이 한 면. 한 편은 여러 쪽에 이어 쓸 수 있고, 책 안의 쪽수는 목차 순서로 이어진다. |
| 원문 | 보고 읽거나 옮겨 쓰려고 담은 글·사진·링크. 읽기만 하거나 같은 원문을 다시 보고 쓸 수 있다. |
| 구절 | 원문에서 골라 읽거나 옮겨 쓰는 부분. |
| 원문 출처 | 문장을 가져온 작품명·쪽수·링크 등. ‘담을 책’은 앱에서 원문을 보관할 위치다. |
| 원문 쪽지 | 원문을 종이 조각처럼 보여 주는 형태. 쪽에 끼우면 그때의 구절·사진·출처를 다시 펼쳐 볼 수 있다. |
| 느낀 점 | 이전에 원문에 남긴 메모. 기존 내용은 원문과 관련 쪽에서 읽고 고칠 수 있다. 새 작성 진입점은 제공하지 않는다. |

책장의 ‘새 책’은 여러 글을 담을 책을 만든다. ‘새 글’은 새 글의 첫 쪽을 연다.
쓰는 쪽과 쪽 목록의 ‘한 쪽 더’는 현재 글에 이어 쓸 쪽을 연다. ‘종이’는 내지의
재질이나 모양을 말할 때 쓰고, ‘필사’는 원문을 직접 옮겨 쓰는 행동을 가리킨다.
‘기록 관리’는 백업·내보내기·휴지통을 여는 이름이다.

## 화면 문구 규칙

1. **버튼은 대상과 다음 동작을 말한다.** ‘필사하기’, ‘사진에서 글자 읽기’처럼
   누르면 바로 일어나는 일을 쓴다. 제목에서 이미 대상을 알려 주는 짧은 화면에서는
   ‘담기’, ‘닫기’처럼 동작만으로 충분하다.
2. **같은 동작에는 같은 말을 쓴다.** 새 자료를 모을 때는 ‘원문 담기’, 담아 둔
   사진에 글을 더할 때는 ‘원문에 글 추가’를 쓴다. ‘담은 원문 찾기’는 앱에 있는
   자료를, ‘새 원문 찾기’는 새로 담을 자료를 찾는다.
3. **결과가 달라지면 문구도 바꾼다.** 원문을 보고 쓰는 동작은 ‘필사하기’로 쓴다.
   ‘담기’는 원문을 보관하고 읽는 동작이며, ‘원문 삭제’는 보관한 원문에 적용한다.
4. **종이의 말로 대상의 크기와 역할을 드러낸다.** ‘새 글’과 ‘한 쪽 더’,
   필사를 시작하는 버튼은 ‘필사하기’로 쓴다. ‘형광펜’은 도구,
   ‘밑칠’은 종이에 남긴 표시다. ‘담을 책’은 보관할 곳이고 ‘원문 출처’는
   가져온 곳의 정보다.
5. **평소에는 짧게, 막혔을 때는 한 문장 더 쓴다.** 안내는 해요체로 쓴다.
   실패했을 때는 어떤 일이 있었는지 말하고, 바로 할 수 있는 다음 행동을 알려 준다.
   좁은 화면에서는 실패한 내용과 다음 행동을 문장 단위로 줄을 나눠 보여 준다.
   버튼은 안내와 따로 둔다. 예를 들어 ‘글을 저장하지 못했어요.
   앱을 닫기 전에 ‘다시 저장’을 눌러 주세요.’라는 안내와 ‘다시 저장’ 버튼을 둔다.
6. **아이콘과 보조 기술에도 같은 말을 쓴다.** 화면 문구, 툴팁, 스크린리더의
   접근성 이름에 같은 동작을 사용한다. 제목과 안내는 한눈에 읽히도록 하고,
   ‘느낀 점’, ‘옮겨 쓰기’, ‘한 쪽 더’의 띄어쓰기를 유지한다.
7. **현재 내용을 보여 준다.** 필사 중에는 지금 따라 쓰고 있는 원문을 표시한다.

## 앱 아이콘과 장서표

iOS·Android 홈 화면과 웹 설치 아이콘에는 쓰는인간체로 새긴 먹갈색 도장을 쓴다.
브라우저 탭에는 잉크 번짐 표식을 쓴다. 책의 장서표를 켜면 책 제목과 소유자
이름 아래 중앙에 같은 도장을 작게 찍는다.

쓰기 도구는 현재 내지의 색을 옅은 미색에 섞고 종이 결을 줄여 표시한다.
원문 목록·읽기·담기·검색 화면은 고정된 미색 바탕을 쓴다.
글꼴과 원문 필터는 선택하면 체크와 옅은 갈색 면을 표시한다. 켜진 스위치는 밤색과 아이보리, 원문 목록은 먹갈색을 쓴다. 펼친 원문과
필사 본문에는 고른 잉크색을 적용한다.

## 버튼과 선택 상태

메뉴와 보조 동작은 밤색 글씨와 아이콘을 쓰고 누르거나 키보드로 초점을 주면
옅게 바탕을 칠한다. 저장과 이어서 쓰기 같은 주 동작은 밤색 면에 미색 글씨를 쓴다.
상태 선택은 체크와 옅은 면으로, 켜고 끄는 조작은 스위치의 위치와 색으로 표시한다.

## 책 주변 화면

쓰기 도구, 원문 보기·찾기, 책장·목차, 쪽수 목록, 책 옮기기,
기록 관리·휴지통과 동기화는 전체 화면에서 연다. 종이 바탕은 안전 영역까지
이어지고, 조작부는 안전 영역 안에 둔다. 책의 단면 장식은 필사면과 표지에 사용한다.
본문이나 목록은 스크롤하고, 확인과 취소만 담는 짧은 대화상자는 작게 연다.

## 쓰기 도구

위쪽의 세워 둔 펜·형광펜·지우개 그림과 이름을 눌러 도구를 고른다. 현재 도구에
체크와 가는 테두리를 두고 아래 두 줄 문장 견본에서 결과를 확인한다.
견본은 고른 내지·글꼴·크기·잉크를 반영하며, 사용자 글이나 쪽을 만들지 않는다.
기본 글자 크기를 줄이지 않고 문장 수와 여백을 줄여 설정이 함께 보이게 한다.
일반 세로 화면에서는 도구 선택과 견본을 위에 고정하고 설정만 스크롤한다.
화면이 낮거나 시스템 글자가 크게 확대되면 전체를 스크롤해 조작부에 접근한다.
글자 크기 슬라이더를 움직이는 동안에도 견본이 바뀌며, 손을 떼면 크기를 저장한다.
도구를 골라도 화면을 유지하고 닫기나 뒤로 가기로 돌아오면 고른 도구로 이어 쓴다.

펜에서는 잉크·글꼴·글자 크기·줄 가이드를 조절한다. 글꼴 이름을 바로 눌러 고르고
현재 글꼴은 밑줄로 표시한다. 폭이 좁거나 시스템 글씨가 크면 글꼴 이름을 여러 줄로
배치한다. 형광펜에서는 밑칠 색과 농도를 조절한다.
기존 밑칠은 글자 영역 전체를 칠하므로 굵기 조절로 표현하지 않는다. 책 안에서는
그 책의 밑칠 설정만, 책 밖에서는 기본 밑칠 설정을 바꾼다. 다른 꾸밈과 내지는 유지한다.

지우개는 상단에 항상 보이며 펜에서 곧바로 고를 수 있다. 밑칠만 지우고 글씨는 유지한다.
지우개를 고르면 지운 견본과 용도 안내를 보여 주고, 밑칠 색·농도는 형광펜에서만 조절한다.
밑칠 표시가 꺼져 있으면 ‘밑칠 켜기’로 기존 색·농도·표시 기록을 유지하며 복원한다.
설정 저장이 실패하면 스크롤 밖의 재시도 버튼을 유지한다.

## 글자 크기

같은 설정에서 한글 자형의 보이는 높이·폭·아래선이 과하게 달라지지 않도록 서체에서
보정한다. 자형의 작은 차이는 유지하고 본문의 크기 설정이나 사용자 글을 바꾸지 않는다.

본문 기본 크기는 20이며 ‘쓰기 도구 → 글자 크기’에서 16부터 30까지 고른다.
슬라이더를 끌어 조절하고 현재 값을 바로 확인한다. 종이 위에서는 두 손가락을
벌리거나 오므려 조절한다. 도구 화면 위쪽의 종이 견본에서 변경한 크기를 확인한다.
본문과 읽는 원문, 줄 가이드는 선택한 크기를 따르며
기기 접근성 글자 확대도 함께 적용한다.

## 낭독

‘쪽 목록 → 이 쪽 낭독’에서 현재 쪽의 필사 본문을 듣는다. 책 상세의 ‘책 낭독’은
책 전체로 열린다. 첫 쪽부터 책 순서대로
읽으며 빈 쪽을 건너뛴다. 화면을 닫거나 앱이 백그라운드로 가면 멈춘다.
사용자가 선택한 따뜻한 여성 저음 하나로 통일한다. 느린 속도와 부드러운 말끝을 유지하고
음색 선택은 제공하지 않는다. 이전 남성·기기 음성 선택값은 사용하지 않는다.
Supertonic 3의 F1으로 기기에서 생성하고 같은 음성 처리를 적용한다. 처음 재생할 때 약 106MB의
음성 모델을 받고 실제 다운로드 진행률을 표시한다. 전에 받은 모델도 다시 사용할 수
있다. 필사 본문은 기기에서 처리하며 음성 모델 사용 조건을 화면에서 열 수 있다.
문단이나 시의 한 연을 이어 읽고, 문단·연 사이나 쪽을 넘길 때는 잠시 쉰다.

## 글씨 쓰는 소리

‘책장 → 설정 → 소리와 효과 → 글씨 쓰는 소리’를 켜면 첫 글자에 사용자가 고른
사각사각한 연필 녹음이 짧게 재생된다. 새 글자가 120ms 동안 들어오지 않으면
60ms로 잦아들어 멈춘다. 빠르게 이어 쓸 때만 한 흐름으로 이어지고, 다시 쓸 때는
녹음의 이어진 위치에서 재생한다. 쓰기 화면을 벗어나도 빠르게 잦아든다. 글씨 쓰는 소리는 기본으로
꺼져 있으며 잉크 반응과 종이 넘김 소리는 각각 고를 수 있다.

## 책장 설정

책장 오른쪽 위의 톱니가 붙은 ‘설정’에서 책장 설정을 연다. ‘서재 기본값’에는 종이 견본을
보며 고르는 ‘기본 종이’와 책갈피·장서표·밑칠 등을 고르는 ‘기본 장식’이 있다.
책 없이 쓴 글과 책에서 따로 고르지 않은 항목이 기본값을 따른다. 책별 선택은 ‘책 꾸미기’에서 한다.
기본 장식 목록에서 작은 견본과 현재 선택을 보여 준다. 한 항목을 누르면 해당 장식의
편집 화면이 열려 미리보기, 표시 여부, 모양과 색을 볼 수 있다. 밑칠의 모양은 ‘농도’,
압화의 배치는 ‘위치’로 표시한다. 선택은 미리보기와 목록에 바로 반영되고, 뒤로 가면
목록에서 보던 자리로 돌아온다. ‘책갈피 설정 초기화’처럼 되돌릴 대상의 이름을 버튼에 쓴다.
아래에는 ‘소리와 효과’, ‘기록 관리’, 지원하는 환경의 ‘기기 동기화’를 둔다. 저장에 실패하면
현재 선택을 보여 주고 ‘다시 저장’으로 재시도할 수 있다.

## 책 꾸미기

책 상세에서 ‘책 꾸미기’를 누르면 해당 책의 설정이 열린다. ‘책 꾸미기 → 표지·내지’에서
표지와 내지를 고른다. 책장 설정의 ‘기본 종이’는 내지를 지정하지 않은 책과 책 없는
필사에 적용한다.
표지를 고르면 닫힌 책, 내지를 고르면 펼친 책을 보여 준다. 책갈피도 펼친 책에서
확인한다. 펼친 책에는 마지막으로 펼친 쪽의 필사 두 줄과 쪽수가 나온다. 빈 쪽이면 최근에 본문을 쓴 쪽을 보여 준다. ‘책 장식’에서는
천 책갈피의 색과 끝 모양, 장서표, 압화를 고른다. ‘쪽 장식’에서는 원문 쪽지, 밑칠,
쪽수 장식, 구분 표시, 날짜인을 고른다. 제본 흔적은 책 안쪽의 표현으로 남긴다. 미리보기의 리본은
책등 가까이에 두고 필사 문구와 여백을 나눈다. 장식 목록에서 한 항목을 누르면 상단 책
미리보기 아래에 해당 장식의 표시·모양·색과 필요한 경우 위치를 보여 준다. 선택을 바꾸면
미리보기에도 바로 반영된다. 편집에서는 장식 이름과 표시 스위치를 한 줄에 두고, 큰 모양
견본을 같은 색으로 보여 준다. ‘색’ 줄에는 현재 색 이름과 눌러서 바꾸는 네 개의 원형 견본을 둔다.
압화 위치도 폭이 충분하면 한 줄에 둔다. 편집 높이를 먼저 확보하고 남은 공간에 책 미리보기를 배치한다.
공간이 더 작거나 시스템 글씨가 큰 경우에는 미리보기와 마지막 옵션까지 한 번에 스크롤한다.
‘목록’이나 뒤로 가기는 보던 목록으로 돌아간다. 선택은 해당 책에 자동 저장하며,
저장에 실패하면 선택을 유지하고 다시 저장할 수 있다. ‘서재 기본값 사용’은 이 책의 해당
장식만 공통 설정을 따르게 한다. 책 없는 글의 기본 꾸밈은
`책장 → 설정 → 기본 장식`에서 바꾼다.

## 필사 카페 · 공간 직접 이용 · 2026-11-22

`책장 → 필사 카페`에서 서 있는 사람의 1인칭 시점으로 들어간다. 사용자가 선택한
중간 규모 디자인의 원목·황동 조명, 중앙 6인 테이블, 창가 책상, 안쪽 자리,
오른쪽 추천 서가·개인 책장·문구대를 실제 3D 기하로 구성한다.

- 화면을 끌어 둘러보고 빈 바닥을 눌러 걸어간다. 가구를 돌아가는 경로를 사용한다.
- 책상을 누르면 그 자리로 걸어가 앉는다. 앉은 책상과 노트를 다시 누르면 쓴다.
- 개인 책장을 누르면 지금 펼친 쪽과 내 책을 고른다. 선택 뒤 원하는 책상에 앉는다.
- 추천 서가에서는 책·저자·추천 이유를 읽고 공식 원문 페이지를 별도 브라우저로 연다.
  추천 책을 구경하는 것만으로 내 책이나 글을 만들지 않는다.
- 문구대를 누르면 기존 쓰기 도구에서 종이·펜·글꼴을 고른다. 구매 기능은 없다.
- 일어나기는 현재 의자 옆으로 돌아간다. 출입문을 누르면 카페 방문을 끝낸다.

하단 자리 선택 패널·방향 버튼·고정 쓰기 버튼은 없애고, 대상을 직접 누르는 조작과
같은 위치에 붙는 작은 이름표를 쓴다. 상단 공간 안내는 키보드·스크린리더와
조작을 찾기 어려운 사용자를 위한 동등한 경로다. WASD·방향키도 유지한다.
카페는 현재 혼자 머무는 공간이다. 빗소리는 직접 켤 때만 재생한다.

입장·쓰기 시작 전에 저장 큐와 한글 조합·계정 상태를 확인한다. 지금 쓰던 글은
기존 입력기·본문·선택을 그대로 유지하고, 다른 책은 마지막 쪽을 연다. 쓰기 시작에
실패하면 카페를 유지해 재시도한다. 공간 탐색만으로 새 책·글·쪽을 만들지 않는다.
`카페로`는 쓰던 자리로 돌아오며, 계정 변경·카페 나가기·앱 재실행은 방문 상태를 지운다.
실제 글은 기존 책 → 글 → 쪽 저장 구조를 따른다.

선택한 이미지 시안은 배치와 재질 방향의 기준이다. 실제 앱은 Flutter의 단순 조명·
깊이 정렬 기반 렌더이며 시안의 사진 같은 표현과 구분한다. 휴대폰의 실제 렌더·
조작·성능과 과거 빈 화면 제보는 [검증 기록](verification.md)을 따른다.

## 책장

작성 화면 왼쪽 위 ‘책장’을 누르면 책장이 열린다. 책이 세 권까지는 최근 책의
표지를 크게 보여 준다. 네 권부터는 위에 최근 책의 작은 표지와 제목을 놓고 아래
선반에는 세 권씩 놓는다. 표지나 최근 책 영역을 누르면 해당 책의 목차가 바로 열린다.
좁은 화면에서는 두 권씩 놓는다. 위쪽 돋보기에서 책 이름을 찾고 ‘새 책’으로 책을 만든다.
‘내 글’에서는 글 한 편의 첫 두세 줄을 종이 한 장에 보여 준다. 아래에 책 이름과
기록 날짜를 표시한다. 종이를 누르면 필사가 열리고, 돋보기에서 찾은 종이를 누르면
검색한 대목이 열린다. ‘책장’과 ‘내 글’은 같은 위치의 버튼으로 오가며, 보관함을
열어 둔 동안 각 목록이 보던 위치를 기억한다. 책 없이 쓴 글도 같은 방식으로 표시한다.

책장에 ‘연습장’ 한 권을 둔다. 처음 열 때 책에 속하지 않은 글을 연습장에 모은다.
표지를 누르면 기록의 첫 두세 줄을 담은 종이 목록이 열리고, 종이를 누르면 이어 쓴다.
‘새 글’은 연습장에 처음부터 쓴다. 쪽 목록에서 이 글을 ‘다른 책으로 옮기기’로 보낸다.
연습장은 편집기, 내지와 책 꾸미기를 다른 책과 공유한다.

## 한 권의 목차와 내지

책 상세는 책 이름·편/쪽 수·지은이를 왼쪽에, 선택한 실제 표지의 작은 견본을 오른쪽에 둔다.
책 낭독과 책 꾸미기는 제목 아래의 보조 동작이다. 목차가 있는 종이와 제본은 고른 책의
내지·장식을 따른다. 큰 시스템 글씨에서는 장식용 표지 견본을 생략해 제목 폭을 확보한다.

**필사 한 번은 글 한 편, 목차 한 항목이다.** ‘필사하기’는 같은 책 안에 새 글의 첫 쪽을
열고 원문 전체를 처음부터 연결한다. 같은 원문을 다시 필사해도 별도 글로 남긴다.
‘이어서 쓰기’는 마지막으로 펼친 쪽으로 돌아가고, ‘한 쪽 더’는 같은 글 안에서 이어 쓴다.
책 없는 필사도 각각 별도 글로 시작할 수 있다. 기존 글과 빈 쪽을 보존하며 과거 기록을
읽는 것만으로 나누거나 다시 저장하지 않는다. ‘새 글’은 목차 제목 옆에 둔다.

목차는 책에 담긴 글마다 한 줄이다. 직접 지은 이름을 우선하고, 자동 이름인 경우
원문 출처 첫 줄의 작품명(가운데점 앞 부분), 내가 쓴 첫 문장, ‘제목 없는 글’ 순으로
표시한다. 주소나 쪽수만 있는 출처는 제목으로 쓰지 않는다. 항목의 ‘글 더 보기 → 글 이름 변경’에서
직접 바꿀 수 있으며 제목과 무관한 본문·커서·쪽은 변경하지 않는다. 목차·검색·TXT·PDF는
같은 제목 기준을 쓴다. 오른쪽 숫자는 해당 글이 시작하는 책 전체 쪽수다.

책마다 마지막으로 펼친 쪽을 저장한다. 해당 쪽이 속한 글에 책갈피를 표시하고 목차
제목을 누르면 그 글의 첫 쪽을 연다. ‘이어서 쓰기 · N쪽’는 하단 전체 너비의 주 동작이다.
낮은 화면과 큰 글씨에서 고정 영역이 본문을 가리면 목록 끝으로 옮겨 스크롤로 접근한다.
상단에서 원문을 열고, 더 보기에서 책 안 검색, 이름, 장서표, 즐겨찾기, PDF를 찾는다.

## 쪽 휴지통

하단 쪽수로 쪽 목록을 열고, 종이의 점 세 개 메뉴에서 ‘휴지통으로 이동’을
고른다. 현재 쪽을 옮기면 다음 쪽을 열고, 다음 쪽이 없으면 이전 쪽을 연다.
각 기록의 마지막 한 쪽은 남긴다. ‘책장 → 설정 → 기록 관리 → 휴지통’에서
원래 기록으로 복원하거나, 확인 후 영구 삭제할 수 있다. 자동으로 비우지 않는다.

## 기록 관리과 문장 찾기 · 2026-11-11

책장의 `설정 → 기록 관리`에서 전체 백업 파일을 내보내거나 가져온다.
백업 파일은 32MB까지 지원한다.
가져오기 전에 백업 날짜와 책·필사·쪽 수를 보여 준다. 기존 기록과 합치며 내용이
충돌하는 필사는 별도로 보관한다. 빈 보관함에 가져오면 백업의 설정과 마지막 위치도
복원한다. 같은 메뉴에서 현재 필사를 TXT, 현재 책을 PDF로 내보낼 수 있다.
책 보관함에서도 책 PDF를 선택할 수 있다. TXT와 PDF에는 필사 본문을 담는다.

`책장 → 내 글`에서 본문·책 이름·저자·필사 제목·기록 날짜를 검색한다. 본문
검색 결과를 누르면 해당 쪽의 문장이 보이는 위치로 이동한다.


책 안에서 오른쪽 위 `+`를 누르면 현재 글의 끝에 빈 쪽을 저장하고 그 쪽을 연다.
빈 책에서는 첫 쪽을 저장한다. 책 밖의 `+`로 시작한 새 글은 첫 입력까지 초안으로 남는다.

## 쓰는 종이와 형광펜

처음 펼친 빈 종이의 첫 줄에는 ‘여기를 눌러 첫 문장을 써 보세요’가 보인다.
입력에 초점이 오면 안내가 사라진다. 글을 한 번 쓰면 새 쪽을 펴거나 앱을 다시 열어도
안내가 나오지 않는다. 현재 글이나 책에 담은 원문과 남겨 둔 출처가 없을 때
하단 버튼은 ‘필사할 글 가져오기’로 표시한다. 자료가 있으면 ‘원문’으로 표시한다.

본문 안을 누르면 커서를 놓고 입력을 시작하거나 유지한다. 마지막 글줄 아래의 빈 곳은
글 끝에서 이어 쓰며, 다시 눌러도 키보드가 닫히지 않는다. 본문 바깥 여백이나 제목을
누르면 입력 위치를 유지한 채 키보드가 닫힌다.
본문이 화면을 채워도 하단 오른쪽의 키보드 아이콘으로 한 번에 내릴 수 있다.
키보드가 닫히면 그 자리에 ‘쓰기 도구’가 돌아온다. 한글 조합 중에는 현재 입력을 유지한다.
키보드를 여닫아도 제목과 종이 위쪽은 같은 위치에 두고, 쓰는 줄이 가려질 때
입력기가 필요한 만큼 스크롤한다. 글은 계속 자동 저장한다.

‘쓰기 도구’에서 형광펜 또는 지우개를 고른 뒤 화면을 닫으면 종이로 돌아온다.
종이의 글자 위를 끌면 형광펜은 밑칠을 미리 보여 주고, 지우개는 지울 범위를 가는 선으로 보여 준다.
손을 떼면 자동으로 저장한다. 지우개는 범위가 겹친 밑칠만 지운다.
같은 곳을 다시 밑칠해도 색이 짙어지지 않는다. 짧게 누르거나 제자리에서
길게 누르면 그대로 있고, 글자가 없는 곳에서 세로로 끌면 스크롤한다.
고른 도구는 하단에 표시되며 누르면 다른 도구를 고를 수 있다. ‘글쓰기로’를
누르면 평소의 커서와 키보드 조작으로 돌아간다. 글쓰기 상태의 구절 선택 메뉴에서도
밑칠을 추가하거나 지울 수 있다.

## 종이에 남는 잉크

글자 사이의 짧고 가는 세로획이 삽입 위치를 가리킨다. 필사와 원문 등록·교정에는
선택한 펜 색을 옅게 쓰고, 느낀 점에는 연필색을 쓴다. 타이핑을 멈춰도 세로획의 크기와 농도를 유지한다. 새로 나타난 한 글자는 옅은
잉크에서 제 농도로 부드럽게 드러난다. 기존 글이나 한글 조합 중인 글은 그대로
표시한다. ‘책장 → 설정 → 소리와 효과 → 잉크 반응’에서 끌 수 있고 OS 동작 줄이기를 따른다.

## 표지도 함께 넘기는 책 · 2026-11-13

앞표지의 천 재질과 책등은 화면 가장자리까지 이어진다. 표지를 누르거나 넘기면
장서표가 나오고, 다음 장에서 첫 필사 쪽이 맨 위부터 열린다. 빈 책에서는 ‘첫 쪽 쓰기’로
시작한다. 책 꾸미기에서 장서표를 숨긴 책은 표지 다음에 첫 쪽이 열린다.
왼쪽 위 ‘책장’을 누르면 책장으로 돌아간다. 앞표지와 장서표를 둘러보는 동안
이어서 쓰는 위치는 유지한다.

마지막 장에서 왼쪽으로 밀면 뒷표지가 오른쪽에서 올라와 종이를 덮는다.
닫히면 천으로 된 겉면이 보인다. 오른쪽으로 밀거나 ‘마지막 장 펼치기’를 누르면
마지막 쪽이 다시 펼쳐진다. ‘한 쪽 더’를 누르면 그 뒤에 새 쪽을 추가한다.
짧게 끌었다 놓으면 시작한 면으로 돌아오며, 넘김 효과 끄기와 OS 동작 줄이기를 따른다.

## 한 장을 들추고 한 권으로 묶기

읽는 동안 아래쪽 바깥 모서리를 끌면 종이가 말리면서 뒷면과 옆 장이 드러난다.
짧게 끌었다 놓으면 현재 쪽으로 돌아온다. 쓰는 동안에는 하단 쪽수 영역에서만
넘길 수 있다. 책으로 묶은 필사는 앞뒤에 쌓인 쪽 수를 양쪽 종이 단면으로 표시하고,
보관함 표지에서도 제본과 종이 단면이 보인다.

보관함의 책 상세에서 린넨 표지와 내지를 각각 선택한다. Aa에서도 현재 책의 내지를
고르거나 기본 종이로 돌릴 수 있다. 내지는 색과 결의 강도가 다르다. Aa의
‘종이 넘김 효과’와 ‘종이 넘김 소리’는 독립 설정이다. 소리는 기본으로 꺼져 있으며,
켰을 때 이동을 마친 뒤에만 실제 종이 넘김 녹음을 재생한다.

## 원문은 책에, 필사는 종이에 · 2026-11-11

`보관함 → 책 → 책 상세 → 원문`이나 쓰기 화면 하단 `원문`에서 원문을 여러 개
등록할 수 있다. 처음 하단 `원문`을 누르면 빈 목록 안내 바로 아래에 ‘원문 담기’와 ‘새 원문 찾기’를 둔다. 출처는 선택이다.
같은 책의 모든 필사와 쪽에서 사용하고, 책 없는 기록은 해당 기록에 저장한다.
‘담기’를 누르면 원문을 보관한다. ‘필사하기’를 누르면 원문 전체로 필사를 시작한다.
**한 쪽에는 원문 하나만 연결한다.** 글이 있거나 다른 원문이 연결된 쪽에서 새 원문으로
필사를 시작하면 같은 글의 끝에 빈 쪽을 열고 그 쪽에 연결한다. 쓰던 원문을 다시 고르면
쓰던 쪽·커서·남은 원문 위치를 유지한다. 원문 본문·사진·출처의
사본으로 보관하며, 줄을 바꾸거나 앱을 다시 열어도 입력을 이어갈 수 있다.
예전에 일부만 필사하던 쪽은 그 내용과 쓰던 위치를 유지한다.
예전에 여러 원문을 연결한 쪽은 본문과 연결 정보를 보존한다. 읽는 중인 원문 하나를
표시하고 ‘이전 원문 기록’에서 나머지 사본을 읽을 수 있다.

필사할 때 키보드가 닫혀 있고 마지막 구간을 쓰는 중이면 아직 쓰지 않은 원문을
본문 다음부터 옅은 밑글씨로 표시한다. 키보드를 열거나 앞선 구간으로 돌아가면
쓰는 자리 아래에서 원문을 읽을 수 있다. 하단 원문은 현재 구간의 확정 입력을
따라가며 따로 스크롤할 수 있다. 키보드가 열린 작은 화면에서는 쓰는 자리 위
여백을 줄이고 하단 원문을 온전한 줄 단위로 보여 준다. 키보드가 열린 동안
제목 위의 잉크 표식은 숨긴다. 쓰는 줄의 공간이 부족하면 원문 선택줄을 접고
하단 ‘원문’에서 열 수 있게 한다. 키보드를 여닫을 때는 보던 위치를 가능한 한
유지한다. 키보드가 열린 상태로 입력을 이어가면 공간에 맞춰 쓰는 줄을 중앙으로
이동한다.
한글 조합 중에는 쓰는 줄의 자동 이동을 멈추고 확정된 글자를 기준으로 원문을 표시한다.
띄어쓰기·문장부호·기호·줄바꿈 차이는 원문을 따라가는 데 영향을 주지 않는다.
다른 글을 적는 동안에는 마지막으로 맞았던 원문 위치에 머문다. 원문과 맞는
구절을 다시 쓰면 그곳부터 이어서 보여 준다. 노트를 다시 열면 저장한 커서까지의
필사와 이 쪽에서 이어받은 원문 위치를 대조한다. 본문 중간에서 멈췄다면
그 줄에 이어지는 원문을 하단에 표시한다.

일반 필기에서는 하단 참조 원문을 표시하지 않는다.
하단 ‘원문’ 버튼은 현재 필사 중인 원문을 바로 펼친다. 연결된 원문이 없으면
현재 책이나 낱장의 원문 목록을 연다. 읽기 화면의 ‘원문 목록’에서 다른 글을 고르고
‘원문 담기’로 새 자료를 더할 수 있다. 읽기에서 목록으로 돌아오면
보던 항목 근처로 이어진다.
패널 상단의 `+ 원문 담기`를 눌러 새 원문을 담는다. 패널을 닫으면 쓰던 줄과 커서로 돌아온다.
기존 기록과 줄에 붙인 원문·출처도 목록에서 볼 수 있다. ‘밑칠만 보기’는
느낀 점에 표시를 남겼거나 필사 본문의 밑칠와 일치하는 원문만 보여 준다.
필사한 쪽을 찾으면 ‘이어서 쓰기’로 쓰던 쪽과 위치에 돌아간다. 같은 원문을 여러 번
필사했다면 지금 펼친 쪽을 우선한다.

원문 목록에는 담긴 책 이름이 보인다. 색인표처럼 구절과 출처를 원문 쪽지에 올리고,
사진이 있으면 옆에 작은 원본 사진을 둔다. 쪽지 사이에는 고른 구분 표시를 쓴다.
원문 패널은 고정된 미색 바탕에 고른 쓰기 글꼴과 펜 색을 사용하고, 선택한 구절에 밑칠의
농도와 색을 적용한다.

원문 읽기는 본문 → 출처와 작은 사진 → 필사하기의 순서로 구성한다. 출처는 제목에
잘라 넣지 않고 본문 아래에서 온전히 읽으며, 비어 있으면 ‘출처 남기기’로 고칠 수 있다.
처음인 원문에는 전체 너비의 ‘필사하기’와 ‘새 글의 첫 쪽에서 시작해요.’ 안내를 둔다.
기존 필사 쪽이 있으면 ‘이어서 쓰기’를 주 버튼으로, ‘새로 필사하기’를 보조 버튼으로 둔다.
새로 필사하기는 새 글의 첫 쪽에서 처음부터 시작하며, 저장된 빈 쪽이나 기존 필사 쪽은 변경하지 않는다.
아직 저장되지 않은 첫 빈 초안은 그 자체를 새 글의 첫 필사 쪽으로 저장한다.
‘이어서 쓰기’는 기존 쪽과 쓰던 위치로 돌아가며 새 글·쪽을 만들거나 본문을 초기화하지 않는다.
필사하기를 연속으로 눌러도 같은 화면에서 쪽을 중복 생성하지 않는다.

새로운 ‘느낀 점 남기기’ 진입점은 제공하지 않는다. 원문을 읽고 필사하는 데 별도 감상을
쓰는 단계를 추가하지 않는다. 기존 느낀 점은 삭제하지 않고 원래 구절 아래에서 읽고
눌러 고칠 수 있다. 한글 조합을 마친 수정은 자동 저장되며, 사용자가 내용을 전부 지우면
메모를 제거한다. 필사 종이에는 저장한 느낀 점만 손글씨로 보여 준다. 본문과 겹칠 때는
해당 글줄이 온전히 보일 때 줄 여백에 작은 연필 표시를 남긴다.

쓰는 쪽 하단에는 원문 구절을 바로 표시한다. 구절을 누르면 ‘필사 원문’에서 사진과
글을 함께 읽고 출처를 확인할 수 있다. ‘다른 원문으로 필사하기’는 원문 목록을 열며,
선택한 다른 원문은 새 쪽에서 시작한다. 아직 남은 원문이 있을 때 ‘한 쪽 더’를 누르면
다음 쪽에서 같은 원문의 남은 부분부터 이어 쓴다.

원문 읽기에서는 글을 먼저 읽고 출처 옆의 작은 원본 사진을 확인한다. 좁거나 큰 글씨
화면에서는 출처 아래에 사진을 두어 줄바꿈과 버튼을 가리지 않는다. 쪽의 ‘필사 원문’
패널은 휴대폰에서 사진 위·글 아래, 넓은 화면에서 사진과 글을 나란히 배치한다.
미리보기에는 담을 때 선택한 영역을 표시하고 사진을 누르면 원본 전체를 확대한다.
사진만 있는 원문은 사진을 넓게 보여 준다.
필사하는 쪽에서는 원문 글만 온전한 글줄로 표시한다. 사진은 ‘원문’을 열어
볼 수 있다.

‘원문 담기’에서 사진을 찍거나 고르고, 복사한 글을 붙여넣거나 직접 적을 수 있다.
본문 아래에서 담을 책을 고르고 원문 출처를 바로 적을 수 있다. 출처는 선택이다.
‘새 원문 찾기’는 빈 원문 목록과 ‘원문 담기’에 표시한다. 외부 공유 안내는
상단 ‘가져오기 더 보기’에서 연다. ‘새 원문 찾기’에서 작품을 둘러보거나 검색한다.
‘작품 둘러보기’에서 내장 작품을 누르면 전문과 출처를 담고 같은 책의 첫 필사 쪽을 연다.
내용을 입력한 원문 초안이 있을 때는 바꿀지 확인한다. 웹 검색에서 작품을 열면
미리 읽을 수 있고 ‘원문 가져오기’로 전문을 등록 초안에 채운다.
긴 원문은 종이 위에서 스크롤해 읽고, ‘글 고치기’에서 전문을 편집한다.
‘고치기 마치기’를 누르면 수정한 원문을 읽는다.
마지막 ‘담기’는 원문을 저장한 뒤 해당 원문을 펼치고, ‘필사하기’는 저장한 뒤
새 글의 첫 필사 쪽을 연다. 저장된 쪽은 그대로 두고 같은 책에 새 글을 만든다.
같은 원문으로 쓰던 쪽이나 저장된 빈 쪽도 그대로 보존한다.
붙여넣기와 공유로 가져온 글에도 같은 동작을 제공한다.
사진이나 링크만 담은 원문은 읽는 화면을 열며, 글이 있어야 ‘필사하기’를 사용할 수 있다.
등록 중 입력하거나 고친 내용이 있으면 닫기·뒤로 가기에서 확인한다. ‘계속 편집’은
초안과 선택을 유지한다. 저장 실패 시 등록 화면에 남아 수정하거나 다시 담을 수 있다.
[원문 담기 화면 기준](book-details-design.md#원문-담기-화면)
목록 위의 ‘담은 원문 찾기’는 지금 열린 책이나 기록에 저장된 원문의 본문과 출처를
검색한다. 같은 줄의 ‘밑칠만 보기’와 함께 쓸 수 있다. 원문 목록은 최근 등록한 순서로
보여 준다. 등록 시각이 없는 이전 원문은 저장 순서를 거꾸로 보여 준다.
입력하면 목록이 좁혀지고, 원문을 읽고 목록으로 돌아오면 검색어를 유지한다.
저장된 원문을 열면 본문을 바로 읽고, ‘원본 사진 보기’에서는 전체 사진을 바로
확대해 볼 수 있다. 글자 영역은 ‘원문 담기’에서 고른다. 사진만 담긴 원문에서는
사진을 바로 보여 준다. 본문이 있는 원문의
하단에는 처음인 경우 ‘필사하기’, 기존 필사가 있는 경우 ‘이어서 쓰기’를 주 버튼으로 둔다.
기존 필사와 별도로 처음부터 옮겨 쓰려면 보조 버튼 ‘새로 필사하기’를 누른다.
읽는 화면에서 ‘원문 더 보기 → 원문 담기’로 새 원문을 담을 수 있다.
‘원문 더 보기 → 원문 수정’에서 본문과 출처를 고친다.
저장에 실패하면 수정창에 입력한 내용이 남아 다시 시도할 수 있다.
원문 등록·사진 인식 결과·원문 수정에서 정리할 문자가 있으면 ‘특수문자 정리’가
나타난다. 누르면 굽은 따옴표,
말줄임표와 긴 대시를 키보드로 입력하기 쉬운 문자로 바꾸고 장식 기호·이모지와
보이지 않는 제어 문자를 정리한다. 결과를 입력란에서 확인하고 ‘정리 되돌리기’로
이전 입력을 복원할 수 있다. 저장 버튼을 누르면 정리한 본문을 저장한다.

저장된 원문을 열고 ‘원문 더 보기 → 원문 삭제’를 선택한다. 확인 뒤 원문과
느낀 점, 원본 사진 연결이 사라진다. 이미 작성한 필사와 필사에 한 밑칠은 남는다.
필사할 때 연결한 출처는 원문을 수정하거나 삭제해도 ‘이 쪽에 남긴 출처’에서 볼 수 있다.
‘새 원문 찾기’는 ‘원문 담기’와 빈 원문 목록에서 바로 열 수 있다.
책장, 내 글, 책 안 찾기, 담은 원문 찾기와 새 원문 찾기에서 자동완성 후보는
커서가 있는 단어 하나만 보여 준다. 후보를 누르면 그 단어를 바꾸고 나머지 검색어를
유지한 채 찾는다. 검색칸은 종이 위 한 줄로 표시하고, 초점이 오면 밑줄과 커서를
먹갈색으로 표시한다.
‘작품 제목’은 한글 제목의 띄어쓰기가 달라도 찾고 일치하는 개별 작품을 먼저 보여 준다.
‘작가 이름’으로 위키문헌 작가 페이지를, ‘기억나는 구절’로 위키문헌과 위키인용집을 찾는다.
‘새 원문 찾기’의 ‘작품 둘러보기’에서 시·소설·수필·기타를 골라 보고, 작품 제목이나 작가
이름을 함께 검색한다. 책에 담은 원문과 같은 종이 쪽지에 작품 제목, 첫 구절, 작가,
갈래와 판본의 대략적인 글자 수를 표시한다. 작품을 미리 읽고 목록으로 돌아와도 보던
곳과 검색 조건이 이어진다. 목록에서 찾지 못한 작품은 ‘웹 검색’에서 제목·작가·구절로 찾는다.
검색 결과 아래에서 네이버 검색으로 이어갈 수 있다. ‘원문 미리보기’가 표시된 작품은
줄바꿈을 유지해 읽으며, 전문과 출처를 등록 화면으로 가져올 수 있다.
원문·작품 목록·네이버 링크는 앱 안의 브라우저에서 열고, 닫으면 보던 검색 화면으로
돌아온다. 웹 미리보기에서 사이트가 화면 안 열기를 막는 경우 ‘새 탭에서 열기’를
사용할 수 있다. 본문을 복사했다면 브라우저 하단에서 ‘복사한 글 가져오기’를 누른다.
복사가 어려우면 화면을 캡처한 뒤 앱으로 돌아와 ‘캡처 가져오기’로 사진을 고른다.
웹 결과의 상세 화면에도 같은 버튼을 둔다. 고른 캡처는 바로 글자를 읽고 ‘원문 확인’을 연다.
설치형에서는 시스템 웹 화면을 닫으면 가져오기 버튼이 보인다.
작품 검색 결과에서 가져온 글과 캡처에는 작품명·사이트·링크를 채운다.
작가 목록이나 네이버에서 가져온 자료의 출처는 등록 화면에서 적는다. 저장은 확인 화면에서 한다.

‘사진 찍기’나 ‘사진 고르기’로 가져온 사진은 바로 읽고, 읽은 글 전체를 종이 위에
펼친다. ‘글 고치기’에서 키보드로 본문을 편집한다. 단어를 두 번 누르면 선택되고,
손잡이로 선택 범위를 조절한다. 선택한 글은 바로 고치거나 잘라낼 수 있다.
‘고치기 마치기’를 누르면 고친
글을 읽는다. ‘필사하기’는 확인한 전체 글과 원본 사진을 보관하고 쓰는 쪽을 열며,
‘원문만 담기’는 같은 자료를 보관하고 원문을 펼친다. 사진 아이콘으로 사진을 확대해
대조할 수 있다. 이미 입력한 글이 있으면 사진을 읽기 전에 교체 여부를 확인한다.

‘원문 확인’에서 ‘글자 영역 고르기’를 바로 연다. 손으로 잡은 영역을 선택하면
그 부분의 글자를 다시 읽는다. 이미 고친 글이 있으면 다시 읽기 전에 확인한다.
사진 편집 더 보기에서 ‘보정해 다시 읽기’와 ‘줄바꿈 정리’를 연다.
인식에 실패하면 다시 읽거나 직접 글을 적거나 ‘사진만 담기’를 고른다. 사진만 담아 둔
원문은 ‘사진에서 글자 읽기’로 편집하고 ‘원문에 글 추가’로 저장한다.
이 기기에 있는 원본 사진은 전체 백업에도 담는다.
기기 간 동기화는 원문과 기존 필사 위치를 전달한다. 다른 기기로 사진을 옮길 때는
백업에서 가져오기를 사용한다.
설치형 앱은 외부 공유로 받은 구절과 사진 한 장을 현재 책에 담을 수 있다.
담을 책은 바꿀 수 있다. URL만 전달되면 링크로 담고, 원문을 열어 링크를
따라갈 수 있다.

## 구분 표시·압화 장식 · 2026-11-11

두 요소를 일반 앱에 기본 표시한다. `책장 → 설정 → 기본 장식`에서 기존 일곱 요소와
같이 각각 모양·색·표시를 선택하고 하나씩 초기화할 수 있다.

- 구분 표시: 목차의 글과 원문 목록의 항목 사이에 세 점·짧은 선·작은 꽃을 선택해 표시한다.
  본문에 문자를 넣거나 쪽을 나누지 않는다.
- 압화 장식: 표지와 장서표의 아래쪽에 잎·들꽃·고사리를 놓는다. 오른쪽·왼쪽·가운데를
  선택하며 글씨와 편집 버튼의 영역을 확보한다. 장서표의 테두리와 별도로 숨길 수 있다.

## 손에 맞춰 넘기는 책

읽기 상태에서 종이를 좌우로 끌면 움직인 폭만큼 옆 장의 실제 글이 드러난다.
짧게 당겼다 놓거나 되돌리면 원래 장에 머무르고, 충분히 당기거나 의도적으로
휙 넘기면 한 장을 마저 넘긴다. 책에 묶인 기록은 책 전체에서 이어지고, 책에 묶지
않은 기록도 독립적으로 넘길 수 있다. 첫 필사 쪽 앞에는 장서표와 제목·저자를 담은 앞표지가 있다. 쪽수 목록에서도
앞표지를 선택할 수 있다. 앞표지와 장서표는 필사 쪽수에 포함되지 않는다.

## 일곱 요소의 재질과 비례 다듬기

책갈피의 무광 직조·박음질과 끝 비례, 장서표의 인쇄 위계·이름 조작, 쪽지의 종이 결·클립/접힘과 테두리 없는 입력, 연필선 두께, 쪽수 문양, 제본 실 고리, 날짜인의 잉크 압인을 정리한다. 기존 모양/색 선택과 기록 데이터는 유지한다. 이후 추가한 세 요소도 같은 종이·천·잉크의 조형 규칙을 따른다.


## 점멸 커서 없는 종이 · 2026-11-10

본문 입력 위치는 글자 사이의 옅은 세로획으로 표시한다. 펜 반응 끄기와 OS 동작 줄이기 설정은 새 글자의 농도 효과에 적용한다.
한글 조합 표시·문자 입력·키보드 이동·탭 위치 지정·글 선택과 수정은 실제 입력기가
처리하며 본문·선택 영역·저장은 보존한다. 제목·원문 등 보조 입력칸은 그대로다.
원문을 옅은 밑글씨처럼 채우는 필사 방식은 별도 제안 단계이며 이번 변경은 본문의
점멸 커서 숨김이다.

## 일반 화면에서 바로 사용

아홉 가지 스타일 요소와 설정은 일반 앱에 직접 적용한다. 모양·색 선택은 즉시 적용·저장한다.
앱 안의 예시 둘러보기와 비영구 데모 진입을 제거한다. 예전 `?demo=reference`·
`?demo=typeface` 링크도 같은 실제 저장소를 열며, 웹에서는 해당 데모 매개변수만
주소에서 정리한다. 기존 원문·책·페이지·도구 선택과 저장 실패 보호를 유지한다.
첫 실행에 합성 문장·책·이름·날짜를 사용자 기록으로 생성하지 않는다.

## 독서와 쓰기의 일곱 스타일 요소

2026-11-10 요청으로 책의 물성과 독서 흔적을 실제 Flutter 화면에 추가했다.

1. 포도빛 천 책갈피: 저장된 현재 글의 상단, 보관함의 현재 글·책 표지, 쪽 목록의 현재 쪽에 나타난다. 현재 위치를 표시하는 장식이다. 목차에서는 책마다 마지막으로 펼친 쪽이 속한 글을 표시한다.
2. 장서표: 보관함 → 책 → 책 선택에서 잉크 표식·이중 테두리·책 제목·편/쪽수·저자를 보여 준다. 주인의 이름이나 필명을 선택적으로 남기고 수정·비울 수 있다. 저자와 소유자의 이름을 구분한다.
3. 원문 쪽지: 접힌 표시와 원문 입력란를 밝은 미색 쪽지, 얕은 한쪽 그림자로 표현한다. 원문 본문은 실제 입력 위젯이다.
4. 밑칠: 구절을 선택하고 ‘밑칠하기’를 누르면 글씨 뒤에 옅은 황토빛을 남긴다. 밑칠과 겹치는 구절을 선택해 ‘밑칠 지우기’를 누르면 해당 부분만 지운다. 책 꾸미기에서 농도와 색을 고른다. 입력 중에는 선택·본문·composing을 되쓰지 않는다. 새로 삽입하거나 대체한 글자에는 표시를 자동 적용하지 않고, 남아 있는 글자의 표시는 이동한다.
5. 판면 장식: 실제 페이지 이동·추가 조작부의 쪽수 양옆에 작은 선과 점을 둔다. 좁은 폭·큰 시스템 글씨에서는 장식을 줄여 조작부와 입력 공간을 확보한다.
6. 제본 흔적: 기존 천 표지에 책등의 가는 눌림선을 더하고, 종이의 위아래 안쪽에는 짧은 직조 헤드밴드를 둔다. 기존 왼쪽 안쪽 음영과 함께 정적으로 표시한다.
7. 날짜인: 내 글에서 첫 쪽을 보관한 날짜를 작은 브라운 도장으로 표시한다. 이미 저장된 과거 페이지의 날짜는 추정하지 않는다. 합성 예시 화면의 날짜·이름·연필 표시는 예시 데이터다.

장식은 입력과 터치를 가로채지 않는다. 책 없는 기록, 바로 쓰기, 종이·펜·글꼴의 독립 선택과 기존 개발 서체의 표기를 유지한다. 쇼핑 기능은 추가하지 않는다.

각 요소는 책장 → 설정 → 기본 장식에서 표시 여부, 세 가지 모양, 네 가지 색을 따로 선택한다. 숨겨도 이름·원문·구절 표시·날짜 데이터는 보존한다. ‘이 요소만 기본으로’는 선택한 요소만 복원한다. 색·치수·상태·동작·저장·조합 규칙과 완료 기준은 [아홉 가지 요소 독립 설계](book-details-design.md)에 정의한다.



## 페이지를 넘기며 쓰기 · 2026-11-10

하단에는 실제 책의 쪽수처럼 현재 쪽수만 작게 둔다. 이전·다음 화살표와
페이지 추가 버튼·전체 쪽수 분수 표시는 제거한다. 저장 상태는 쪽수 아래에 작게
표시하고 저장 실패는 기존 배너와 재시도로 명확히 알린다. 도구와 더 보기는 유지한다.

읽는 상태에서는 종이 위를 좌우로 쓸어 넘긴다. 왼쪽은 다음 쪽, 오른쪽은 이전
쪽이다. 마지막 쪽에서 왼쪽으로 넘기면 같은 필사에 새 빈 종이가 생긴다. 첫 쪽에서
오른쪽으로 넘기면 그대로 머문다. 짧은 손 떨림·세로 스크롤은 페이지를 만들지 않는다.
마우스로 본문을 드래그하면 글을 선택하고, 쪽수 영역은 마우스 드래그도 지원한다.

형광펜과 지우개를 쓰는 동안 본문을 끌면 도구가 움직인다. 하단 가운데 영역을
좌우로 쓸어 페이지를 넘길 수 있다. 글쓰기 상태에서 쪽수를 누르면 본문이 담긴 종이
미리보기가 열려 페이지를 고를 수 있고, 보조 화면의 ‘한 쪽 더’도 사용할 수 있다.
상단 브랜드·본문·하단 도구를 포함한 화면 전체가 한 장으로 넘어가는 연출을 유지한다.

첫 빈 종이에서 명시적으로 다음 쪽으로 넘기면 첫 쪽과 둘째 쪽을 저장한다.
앱을 열거나 포커스만 주는 것으로 빈 기록을 저장하지 않는다. 자동 페이지 분할은
하지 않는다. 각 쪽의 본문·선택 영역·스크롤은 이동과 재실행 때 복원한다. 스크롤해 둔
쪽이나 원문을 고른 필사 쪽은 저장 위치에서 바로 펼친다.

새 페이지는 전환 중에도 바로 입력할 수 있다. 한글 조합 중에는 이동·추가를 막고,
저장 실패 시 현재 글을 유지하며 재시도 후 이동한다. OS 동작 줄이기 설정에서는
즉시 전환한다. 넘김 소리는 후속 범위다.

내 취향으로 쓰고, 한 권으로 남기는 즐거움.

## 글씨 가독성

쓰는 인간체 0.007의 실제 획 두께를 유지한다. 일반 조작/안내 문구는 최소 14px,
기본 본문은 20으로 표시하며 ‘쓰기 도구 → 글자 크기’에서 조절한다. 시스템 글씨 확대는
선택한 크기에 그대로 적용한다. 작은 표지 썸네일의 장식 글씨는 표지 비율을 유지하며
같은 책의 제목은 옆의 실제 목록 글씨로 읽을 수 있다. 날짜 안내는 좁으면 줄을 바꾼다.
입력·선택·composing을 다시 설정하지 않는다.

## 현재 UX · 바로 쓰는 종이

2026-11-10 사용자 피드백을 반영한 현재 기준이다. 앱을 열면 마지막 글 또는 빈 종이가 바로 보인다. 책 이름·종이·펜·글꼴 선택을 입력의 선행 조건으로 두지 않는다. 한 번 눌러 입력하고 자동 저장한다. 빈 종이를 열거나 포커스만 주는 것으로는 기록을 만들지 않는다. 첫 글자를 쓰거나 책 없이 원문을 담으면 실제 글을 저장한다.

첫 화면은 책장, 새 글, 본문, 쓰기 도구와 저장 표시로 구성한다. 원문은 하단 왼쪽, 쪽 목록은 가운데 쪽수로 연다. 쪽 목록에서 현재 쪽의 낭독과 현재 글을 책에 넣거나 옮기는 동작을 연다. 책장의 설정에는 기록 관리, 소리와 효과, 기본 종이, 기본 장식을 두며 동기화가 가능한 환경에서 기기 동기화도 제공한다. 책장/책 상세를 거쳐야 쓰는 흐름과 다섯 개 하단 메뉴는 현재 UX에서 사용하지 않는다. 책 없는 기록을 먼저 쓰고 이후 책으로 묶어도 같은 본문·페이지·선택 영역을 유지한다. 상단 ＋에는 책 안에서 ‘한 쪽 더’, 책 밖에서 ‘새 글’ 접근성 이름을 붙인다. 하단 ‘쓰기 도구’에서는 잉크와 글꼴을 바꿀 수 있다.

최신 종이 시안을 실제 작성 화면에 반영한다. 브랜드 잉크는 #70472F, 기본 종이는 #F7F2E8, 기본 본문은 #302C27이다. 작성 화면 상단의 제목을 양옆 버튼과 같은 높이에 두고, 화면의 왼쪽에는 얕은 책 안쪽 음영을 둔다. 작성지·상단·하단을 같은 종이 면으로 연결하며 본문을 별도 카드에 넣지 않는다. 종이 결은 은은하게 유지한다. 상단에는 책장·제목·＋, 하단은 왼쪽 원문, 가운데 쪽수와 저장 상태, 오른쪽 쓰기 도구 순서로 둔다. 키보드가 올라오면 제목과 본문 위쪽 여백을 유지하고 키보드가 가리는 아래쪽만 조정한다. 책에 묶인 쪽에서는 상단 제목에 책 이름이 나온다. 책 상세의 연필 버튼으로 이름을 바꾼다. 빈 종이의 본문은 비어 있다. 본문과 제목·메뉴·도구·대화상자의 기본 글꼴은 실제 쓰는 인간체다. 기존 페이지에도 한 번 적용하며 이후 사용자가 고른 다른 본문 글꼴은 유지한다. 종이·표식은 이미지 소재, 본문·조작부는 접근성과 입력을 유지하는 실제 Flutter 위젯이다. 입력 중 작은 펜 반응은 유지한다.

## 제품 원칙

타이핑 전용 필사 앱이다. 단정한 화면에 실제 종이의 재료감과 편안한 한글 본문 활자를 표현한다. 종이·펜·글꼴은 독립적으로 선택하며, 펜에 작은 반응과 글쓰기 소리, 페이지 넘김 소리를 단계적으로 붙인다. 소리와 움직임은 끌 수 있게 한다. 한글 입력과 기록 보존이 모든 연출보다 우선한다.

책 → 글 → 쪽 구조. 책 없이 먼저 쓰고, 나중에 기존 책에 묶을 수 있다. 빈 서재에서 시작하며 샘플 문장을 사용자의 기록으로 자동 생성하지 않는다. 초기 앱에는 쇼핑·결제·오프라인 샵 메뉴가 없다. 오프라인 샵은 장기 브랜드 계획이다. ‘쓰는 인간체’는 현대 한글 11,172자·자모·영문·숫자를 지원하는 개발 중 선택지다. 기본 글꼴은 쓰는 인간체이며 지원 범위 밖에는 SIL OFL의 번들 나눔명조 등을 사용한다. 문자 지원 범위와 출시 완성도는 구분하며, 최종 광학·실기기 검수 전에는 완성 서체로 표시하지 않는다.

## 구현 순서

사용자의 서체 적용 요청에 따라 Aa → 글꼴에 ‘쓰는 인간체 · 개발 중’을 추가했다.
선택하면 본문과 브랜드 제목에 실제 개발 TTF를 사용하고, 미지원 글자는
나눔명조 등으로 보완한다. 전체 현대 한글을 지원하지만 개발 중임을 도구 화면에 명시한다.
기존 기록은 쓰는 인간체로 한 번 전환한다. 본문·선택·스크롤·종이·펜을 보존하며 이후 사용자가 선택한 다른 글꼴은 유지한다.

이전 데모 주소도 일반 앱으로 열린다. 실제 기록에 아홉 가지 요소와 현재 기본 서체를 바로 적용한다.

1. 책 생성 → 필사 작성 → 실제 로컬 저장 → 재실행 시 본문과 마지막 위치 복원. 종이 질감과 나눔명조를 이 단계부터 적용한다.
2. 종이·펜·글꼴을 독립적으로 선택. 폰트와 종이 변경 시 본문·커서를 보존한다.
3. 여러 필사의 제목·순서·묶기 관리. 현재는 필사 추가, 기록 선택, 책 없는 기록 묶기만 가능하다.
4. 버전이 있는 백업·복원. 복원 전 검증과 기존 자료 보호. 웹의 기기 간 동기화는 docs/sync.md에 정의한다.
5. 펜의 작은 반응과 소리. IME 조합 중 반응으로 입력을 방해하지 않는다. 실제 폰에서 지연을 확인한다.

현재 범위에서는 페이지를 사용자가 직접 추가한다. 글을 자동 분할하거나 입력 중 재배치하지 않는다. 삭제·공유·쇼핑은 구현하지 않았다. 웹에서는 같은 ChatGPT 계정의 PC·모바일 기록을 동기화한다. 설치형 앱 계정 인증은 아직 연결하지 않았다.

## 참조 이미지 적용 · 이전 디자인 방향

아래는 초기 참조 이미지 적용 기록이다. 현재 화면과 진입 흐름은 위의 '현재 UX · 바로 쓰는 종이' 기준을 따른다.

첨부 이미지의 책장, 책 상세, 필사, 종이 선택, 글꼴 선택을 실제 Flutter 화면에 반영한다. 종이빛 #F7F2E8, 잉크 브라운 #5B4636, 책표지 그린 #4E5A42, 고요한 블루 #5B6F8E, 포도레드 #7A4A4A를 기준으로 한다. 개발 중인 쓰는 인간체는 잠금 상태로 보여 주고 실제 사용 가능한 나눔명조/나눔고딕만 선택할 수 있다. 쇼핑·오프라인 샵 메뉴는 추가하지 않는다.

종이·펜·글꼴의 독립 선택, 줄 가이드, 원문 메모, 즐겨찾기를 제공한다. 가는 세로 커서가 실제 입력 위치를 표시하고, 확정된 글자는 잠깐 짙어진다. 한글 조합 중에는 위치만 표시하고 선택 영역을 펼치면 커서를 숨긴다. 글자 반응은 책장의 설정에서 끌 수 있고 OS 동작 줄이기 설정을 따른다. 백업·복원과 쓰기·종이 넘김 소리는 후속 범위다.

## 기기 간 이어 쓰기

로컬 저장을 유지하면서 같은 계정의 PC·모바일 브라우저에서 책·필사·페이지·마지막 위치·도구 설정을 동기화한다. 오프라인 수정은 재연결 시 반영하고, 서로 다른 수정본은 별도의 필사로 보존한다. 예시 책장은 동기화하지 않는다. 기존 익명 기기 기록은 사용자가 명시적으로 가져온다. 현재 설치형 앱은 로컬 저장만 제공한다.

## 고요한 뜰 · 2026-11-22 구현

카페 안쪽 오른쪽 아치를 눌러 걸어가면 꽃과 두 나무, 금붕어 세 마리의 연못이 있는
별도 뜰로 들어간다. 연못을 누르면 가까이 바라보고, 벤치를 누르면 쓰기를 시작하지
않고 앉아 쉰다. 쉬는 동안 물체 이름표를 숨겨 시야를 비운다. 작은 종과 찻잔은 가까이에서
직접 눌러 소리를 듣거나 차를 따르며, 먼 곳에서는 걸어간 뒤 다시 누른다.
물소리는 상단에서 직접 켜고, 방을 바꾸거나 앱을 떠나면 멈춘다. 자동으로 다시 켜지 않는다.
뜰의 노트를 눌러 기존 글을 이어 쓰거나 ‘카페로’ 문을 통해 돌아갈 수 있다.
타이머·완료·새 기록 생성을 쉼의 조건으로 추가하지 않는다. 조작은 공간의 물체와
기존 공간 안내를 함께 제공하며, 동작 줄이기에서는 물고기·잔물결을 정지시킨다.


## 1인칭 걷기 · 2026-11-22

사용자 요청으로 아바타·3인칭·시점 전환 버튼을 제거한다. 1인칭에서 공간과 글에
집중하며 바닥 클릭은 완만한 출발/정지와 이동 중 목적지 변경을 유지한다. 화면을
끌면 시선을 돌리면서 이동과 예약 동작을 취소한다. WASD/위아래 키는 누르는 동안
걷고 놓으면 멈추며 초점·앱 이탈에서도 중지한다. 기존 뜰·벤치·연못·종·차·쓰기와
입력/저장 흐름을 유지한다. 하단 방향 버튼은 추가하지 않는다.

바닥은 사용자가 선택한 B안의 낮은 명도 모카 브라운 석재를 적용한다.

## 모카 석재와 카페 실내 세부 · 2026-11-22

사용자가 바닥 B안을 선택하고 전체 실내 구현을 요청했다. 카페 바닥에는 낮은 명도의
모카 브라운 석재와 2mm 줄눈을 적용한다. 벽과 종이의 밝기를 유지하고, 미장 벽의
잔결·원목 걸레받이와 입구 패널·천장 경계·황동 벽등·식물과 풍경 액자로 재료와 깊이를
구분한다. 카운터에는 세이지색 타일 벽·간판 액자와 그림 조명·커피 기계와 잔을,
책상에는 코스터·펜 끝·책의 종이와 제본·가지가 꽂힌 작은 화병을 둔다.

추가한 벽 장식과 물건은 기존 벽 또는 가구 영역 안에 둔다. 중앙 통로와 의자 뒤
보행, 책/도구/뜰의 직접 선택, 아바타 없는 1인칭과 기존 필사 입력·저장을 유지한다.
생성 B안은 재질 방향의 기준이며 실제 Flutter 렌더는 사진이나 경로 추적 렌더가 아니다.


## 창가와 직접 들어가는 하나의 정원 · 2026-11-22

창밖에 별도 사진을 보여 주던 구현을 교체한다. 실내에서 보이는 연못·금붕어·나무·꽃과
걸어 들어간 뜰은 하나의 3D 장면을 공유한다. 창가 뒤쪽 유리문으로 들어가며, 뜰에서
돌아보면 같은 실내 창과 가구가 보인다. 연못은 창 가까이에 두고 통로와 벤치를 분리한다.
창을 바라볼 때도 물고기와 물결이 움직이며 동작 줄이기/백그라운드에서는 멈춘다.

승인한 시안의 조명 방향을 유지하면서 등 주변·책상·벽등·선반의 빛을 국소적으로 계산한다.
벽은 회벽 재질, 원목 창틀과 몰딩, 패널로 마감한다. 모카 바닥과 기존 1인칭 조작·
필사·저장 흐름은 유지한다. 식물은 3D 위치에 놓인 투명 사진 평면이며 실제 볼륨 메시나
사진 같은 실시간 조명은 아니다. 결과는 생성 시안과 구분한 실제 실행 화면으로 확인한다.


## 하루 끝에 머무는 카페 · 2026-11-23 구현

사용자가 공간 평가와 보완 시안을 승인해 구현을 지시했다. 중앙 큰 테이블과 가구/통로
배치를 유지하고 입장 위치를 조금 앞으로, 시선을 조금 위와 안쪽 자리 쪽으로 옮긴다.
주변의 기본 빛은 낮추고 종이와 책등에 국소 등빛을 남긴다. 안쪽 자리와 앞 창가의
의자에는 올리브 방석을, 안쪽 책상에는 차와 펜·책갈피를 둔다. 추천 서가 일부에는
기존 추천 동작으로 연결되는 표지 세 권을 강조한다. 새 사용자 기록은 만들지 않는다.

이름표는 3.5m 안에서 바라보는 대상 중 하나만 보인다. 앉아 있는 자리의 노트 동작은
유지하며 이름표를 종이 아래로 옮긴다. 바닥/물체 직접 클릭과 공간 안내의 전체 목적지·
키보드/보조 기술 경로는 그대로다. 처음 걷기 안내는 조작 뒤에 물러나며 이동·쓰기·
쉬기·실패 안내는 필요한 때 보여 준다. 정원은 같은 공유 장면의 두 나무를 유지하고
담장 아래 낮은 식재를 연결하며 석재 덮개와 자갈 경계를 더한다.


## 나만의 카페와 물건 상태 보존 · 2026-11-23 제안 · 미구현

사용자는 넓은 정원 연결문 방향을 좋아한다고 확인했고, 개인 공간으로 가구/물건의 위치와
상태를 저장하며 꾸미는 요소를 원했다. 넓은 문과 더 밝은 따뜻한 빛을 유지한
[개인 공간 시안](../design/cafe/20261123/personal-space-study/personal-space-concept.jpg)을 제안했다.

꾸미기 모드에서 물건을 선택해 옮기기/돌리기/바꾸기를 제공하고 일반 탐색 중에는 편집
메뉴를 숨긴다. 우선 책상 위 소품, 조명 밝기/색, 방석·액자·식물과 서가의 책 배치를
다룬다. 위치·방향·선택한 모양과 지원하는 물건의 상태를 확정 후 저장하고 다시 들어올 때
복원하는 기능을 계획한다. 문 앞과 주요 통로는 비워 두며 쇼핑/결제/재화를 추가하지 않는다.
현재 고정 메시/방문 상태에는 이 영구 저장 기능이 없다. 공개 GitHub Pages의 첫 구현은
같은 브라우저 저장 범위이며 기기 간 공유는 계정 동기화의 별도 연결/검증이 필요하다.


## 개인 공간의 액자와 원화 · 2026-11-23 시안 · 미구현

사용자가 액자와 그림의 디테일 보완을 요청했다. [벽면과 확대 시안](../design/cafe/20261123/frame-art-study/frame-art-detail-concept.jpg)은
월넛 식물화, 밝은 오크의 물빛 수채화, 작은 책/연필 드로잉을 제안한다. 프레임 두께와
모서리 이음·안쪽 깊이, 미색 매트지의 사선 단면과 종이 여백, 벽에서 떨어진 그림자를
표현한다. 밝고 따뜻한 조명에서 원화가 읽히도록 유리 반사는 절제한다.

개인 공간에서는 프레임 재질/그림/종이 여백을 독립적으로 고르는 방향으로 계획한다.
큰 그림 하나와 작은 그림의 여백을 유지하며 모든 벽을 장식하거나 같은 로고를 반복하지
않는다. 실제 배치와 선택/저장 기능은 아직 구현하지 않았다.


## 나만의 필사 공간 · 2026-11-23 구현

사용자가 개인 공간과 액자/원화 시안을 보고 작업을 지시했다. 정원 연결문을 약 1.8m로
넓히고 창가 끝 책상과 안쪽 자리를 조정했다. 문 앞을 비우며 기본 빛을 밝게 하고, 원목
프레임/매트/독립 원화의 구조와 세 종류의 창작 그림을 실제 렌더에 연결했다.

상단의 붓이나 물건 길게 누르기로 꾸미기에 들어간다. 책상과 의자는 한 묶음으로 옮기고,
큰 책상의 찻잔·노트·연필·화병은 개별 위치/방향을 조절한다. 화분과 액자의 위치도 바꿀
수 있다. 물건 목록을 통한 선택과 조금씩 옮기는 버튼도 제공한다. 통로/문 앞·가구 겹침,
책상 위 지지 범위와 벽 위치를 벗어나는 변경은 적용하지 않는다. 일반 탐색은 기존 1인칭
직접 클릭/걷기와 공간 안내를 유지하고 편집 메뉴는 꾸미기 중에만 보인다.

액자 재질/그림/종이 여백은 액자마다 독립 선택한다. 조명 밝기/온기, 방석·잔·화분의
색은 공간 공통으로 고른다. 잔의 빈/찬 상태·노트 열림·정원 문 열림, 뜰의 찻잔 상태와
나의 책장에서 고른 책도 기억한다. 닫힌 문/노트는 먼저 눌러 연 다음 이용한다.

꾸미기 완료는 저장 성공 후에만 끝난다. 변경 취소는 마지막 저장 배치를 복원한다. 저장
실패는 편집 상태를 유지하고 재시도를 안내하며, 불러오기 실패는 새 기본 배치로 덮어쓰지
않는다. 글의 입력·종이·펜·글꼴 설정은 바꾸지 않는다.
설치형은 별도 SQLite 설정 영역, 공개 웹은 같은 브라우저의 저장 공간을 사용한다.
계정이 있는 환경은 계정 범위를 분리하지만 공간의 기기 간 동기화와 책 백업에 공간을
포함하는 기능은 이번 범위에 없다. 음향은 다시 입장할 때 자동 재생하지 않는다.


## 카페의 수채화 감성 · 2026-11-23 사용자 요청 · 디자인 시안

사용자는 각져 보이는 물체를 부드럽게 하고 요소 하나하나에 수채화 감성을 살리길
요청했다. 앞으로 카페에 더하거나 수정하는 가구·소품·벽·바닥·조명·식재·연못에
같은 표현 기준을 적용한다. 원목과 따뜻한 빛, 종이와 잉크를 중심에 둔다.

- 형태: 상판 모서리, 의자 등받이·좌판, 찻잔과 등갓은 둥근 윤곽과 자연스러운 곡면을 쓴다.
- 재질: 원목 결·미장·종이·천·잎마다 절제된 붓질과 안료의 농담을 준다. 가까운 글과
  펜의 형태는 읽히게 두고, 물체와 통로의 경계가 사라지도록 흐리지 않는다.
- 빛: 따뜻한 국소 빛과 부드러운 접촉 음영을 사용한다. 밝은 종이와 걸어갈 길은 확보한다.
- 일관성: 실내에서 보는 정원과 직접 걷는 정원에 같은 재질·색·형태 기준을 쓴다.

[전체 공간과 소품 시안](../design/cafe/20261123/watercolor-study/watercolor-cafe-concept-v1.jpg)은
현재 실행 캡처를 배치 참고로 만든 생성 이미지다. 수채화 처리 강도와 구체적인 형태는
검토 전이며, 앱의 3D 메시·재질·렌더러·저장 동작·공개 웹에는 아직 적용하지 않았다.


## 수채화 3D 공간 · 2026-11-23 구현

사용자가 시안 같은 방식으로 메타버스를 구성할 수 있는지 요청해 해당 방향을 실제
1인칭 공간에 연결했다. 둥근 상판/좌판·원형 의자 다리·연속 곡면의 등갓과 찻잔,
두께가 있는 잔 손잡이와 굽은 잎을 사용한다. 목재는 창작한 수채화 재질을 오크와
월넛 색으로 나누고, 벽·석재·천·도자기·종이·화분과 소품에는 절제된 안료 농담을 준다.
실내/정원의 광원은 따뜻하게 유지하며 기본 확산광을 밝히고 날카로운 광택을 낮췄다.

정원의 나무/꽃은 수채화 알파 재질을 쓴다. 잎·꽃 밖의 아주 옅은 배경색은 재질의
부드러운 투명도 마스크로 줄인다. 금붕어·연못 돌의 색 번짐은 물체의 로컬 좌표에
고정한다. 기존 1인칭 걷기·직접 선택·같은 정원 연결·물건 꾸미기와 공간 저장을 유지한다.

생성 시안의 완성도를 그대로 보장하는 것은 아니다. 실제 구현은 Flutter의 투영/면 정렬과
단순 조명을 사용하며 식물은 카메라를 향하는 그림 평면이다. 붓질과 종이 결은 물체
재질에서 표현하고 글쓰기 본문이나 화면 전체를 흐리는 효과는 적용하지 않는다.


## 선명한 수채화 화면과 넓은 카페 출입문 · 2026-11-23

사용자가 휴대폰 화면의 뿌연 느낌과 카페 정문 패널의 격자 깨짐을 제보하고 개방감을
요청했다. 기존 수채화 방향 안에서 직접 수정했다. 정원 연결문이 아니라 카페 종료를
담당하는 정문이다. 상단 112px의 밝은 그라데이션과 렌즈 비네트를 제거하고 조작부에만
좁은 종이색 배경을 둔다. 목재 표시 해상도를 768px로 높이고 안료의 대비/색을 보존한다.

출입문은 약 2.2m 유리 폭과 얇은 원목 프레임·작은 중앙 이음·세로 손잡이로 구성한다.
문 뒤의 큰 원목 판, 불투명 올리브 패널과 큰 글자판을 없애고 벽에도 실제 개구부를 낸다.
유리 너머에는 간단한 현관 전경을 그리되 별도 방문/외부 공간 기능은 추가하지 않는다.
유리 면은 기존 ‘출입문’과 같은 카페 나가기 동작이며 주변 벽 마감과 꾸미기 통로를 맞춘다.
기존 정원/실내 연결과 개인 배치/상태 저장, 필사 입력과 기록 구조는 유지한다.


## 물건별로 꾸미는 필사 카페 · 2026-11-24 구현

승인한 수채화 방향을 유지하면서 중앙·창가 세 자리·안쪽 자리의 책상, 의자, 노트,
연필, 잔, 화병을 독립 아이템으로 나눴다. 기존 자리 묶음은 ‘함께 옮기기’로 남기고,
책상만 옮기면 그 위 소품은 따라가며 의자는 자기 위치를 유지한다. 의자를 직접 누르면
그 의자 위치·방향에 앉고 뒤나 옆의 빈 통로로 일어난다. 아바타·3인칭·쇼핑은 추가하지 않는다.

서가의 세워 둔 책 34권과 포개 둔 책 묶음, 카운터의 머신/그라인더/물병/리넨/작은 책과
잔들도 개별 선택·배치 대상으로 분리했다. 머신 위·추출대의 잔은 머신에 놓인 소품이다.
서가 책의 색과 표지 보임은 장식 상태이며 실제 추천 작품·내 책장의 콘텐츠를 바꾸지 않는다.
벽/서가의 고정 구조, 벤치와 건축 마감은 이번에도 고정 요소다. 한 의자의 다리 하나나
한 가지의 잎 하나까지 별도 꾸미기 항목으로 만들지는 않는다.

꾸미기에서는 물건 목록을 가구/소품/책/조명/식물/그림으로 좁힐 수 있다. ‘가까이 보기’는
발 디딜 수 있는 위치에서 선택한 물건을 보며, ‘이 물건만 처음처럼’은 그 물건의 배치와
꾸밈만 되돌린다. 잔의 색·차 종류·빈 상태, 노트 표지·열림, 연필의 칠, 화병·가지,
의자의 원목·방석, 식물·책·리넨의 색은 각 물건에 저장한다. 펜던트·벽등은 하나씩 켜고 밝기를
고르며 방 전체 밝기/온기는 별도로 유지한다. 평소에는 가까운 잔·노트·등을 직접 눌러
사용하고, 배치 메뉴는 꾸미기에서만 보인다.

잔의 연속 손잡이·입구 안쪽·받침, 노트의 완만한 종이 굴곡과 페이지 가장자리, 연필의
끝과 지우개, 화병의 입구·가지·잎을 근접 시점에서 다듬었다. 정원의 주요 나무 두 그루와
꽃 무리는 실제 가지·잎·꽃잎 메시이고 각각의 위치/색을 저장한다. 연못과 출입 통로,
휴식 벤치의 접근을 방해하는 식재 이동은 제한한다. 수채화 재질은 같은 종류의 물건끼리
공유하되 물건별 배치·선택·상태는 독립적이다.

기존 v1 공간 설정은 v2로 읽으며 이전 묶음/소품 ID와 공통 색의 기본값을 유지한다.
새 발자국 검사에 걸리는 이전 배치도 지우지 않고 불러와 수정 안내를 보여 준다. 새
배치는 상판의 가장자리·다른 물건과의 겹침·문 앞·보행 경로를 확인한다. 손상된 저장
데이터나 저장 실패를 빈 공간으로 덮어쓰지 않는다. 저장 범위는 기존과 동일하며 같은
기기/브라우저의 별도 공간 설정이다. 기기 간 동기화나 책 백업에 공간 설정을 추가하지 않는다.

[잔과 원목 상판](../design/cafe/20261124/individual-items/cup-close.jpg),
[휴대폰 편집 화면](../design/cafe/20261124/individual-items/cup-controls-phone.jpg),
[같은 정원의 입체 식재](../design/cafe/20261124/individual-items/garden.jpg)는 생성 시안이 아닌
Flutter 테스트 렌더다. 근접 검수 시점과 실제 걸을 수 있는 위치, 실기기 검증 범위는
[검증 기록](verification.md)에서 구분한다.


## 아이템 색 선택과 실제 재질 · 2026-11-24 보완

먹갈색 의자는 나무 결을 유지한 채 더 어두운 색을 입힌다. 나무의 올리브/연녹/회녹은

맞추고, 색을 고르면 꽃잎 또는 맨 위 표지가 그 색이 된다. 기본 모습과 기존 배치/기록은

## 물건을 직접 사용하는 카페 · 2026-11-24

짧게 누르면 사용하고, 길게 누르면 기존 꾸미기로 들어간다. 찻잔은 받침을 남겨 두고
눈앞으로 들어 올린다. 다시 누르면 한 모금씩 마시며, 빈 잔에는 차를 따를 수 있다.
책은 서가에서 꺼내 펼치거나 덮고 추천/개인 책 목록을 살펴본 뒤 제자리에 꽂는다.
노트는 실제 종이 면을 접어 여닫고, 펜을 들어 필사하기를 누르면 기존 편집기로 이어진다.
이동이나 꾸미기를 시작하기 전에는 손에 든 물건을 원래 자리에 내려놓는다.

의자는 가까이에서 당겨 앉거나 일어날 수 있고, 통로를 침범하지 않는 범위에서 다시 넣는다.
조명은 켜기/끄기와 밝기, 화병은 가지 바꾸기/비우기, 화분은 물 주기를 지원한다.
액자는 감상 안내와 길게 눌러 꾸미기로 이어진다. 카운터 도구·천·책 묶음은 가벼운 터치와
기존 꾸미기를 지원하며, 커피 제조나 모든 물건의 물리 시뮬레이션을 구현한 것은 아니다.

남은 차·조명·가지·물 준 상태·의자 위치는 기존 공간 저장소에 보관한다. 손에 든 상태와
동작 중간 자세는 저장하지 않는다. 중단하면 원래 위치로 돌아오고 완료되지 않은 모금은
차감하지 않는다. 소리는 기존 소리 켜기 선택을 따른다. 하단 이동 버튼이나 아바타는 없다.

## 돌아오고 싶은 카페 · 2026-11-24

사용자는 개별 물건의 동작만으로 방문하고 싶은 마음이 크게 생기지 않는다고 말했다.
다음 방문을 기다리는 이유로 창가의 한 장면, 나의 자리, 오늘 만나고 싶은 문장을 연결했다.
생성 시안은 분위기의 제안이며 실제 Flutter 렌더나 휴식 효과의 검증으로 소개하지 않는다.

- 처음 들어오면 ‘오늘은 한 줄만 남겨도 좋아요.’라는 작은 안내에서 머물 자리를 고른다.
  ‘비 오는 창가에서 쉬기’는 저녁 비 연출을 켜고 실제 통로를 걸어 창가에 앉는다.
  쓰지 않고 쉬는 방문도 가능하며, 그 행동만으로 글이나 책을 만들지 않는다.
- 창가에는 원목 스탠드와 실제 종이 쪽지를 두었다. 낮/해 질 무렵/비 오는 저녁을 고를 수
  있고, 비는 같은 정원과 창유리에만 보인다. 소리는 기존에 직접 켜는 선택을 따른다.
- ‘나의 자리’에서 지금 앉은 의자를 기억한다. 아직 정하지 않았다면 첫 필사 자리를 기억한다.
  다음 방문에 그 자리로 걸어 돌아가며 정원 자리도 유리문을 통해 이어진다.
- ‘오늘의 문장’은 지친 날/다시 시작하는 날/그냥 좋은 날로 고른다. 앱을 위해 준비한
  자체 문장 여섯 편 중 날짜와 주제에 맞는 한 편을 펼친다. ‘이 문장 필사하기’를 누를 때만
  출처를 함께 보관하고 새 글 한 편을 만든다. 기존 글과 쓰던 쪽은 보존한다.
- 지금 쓰던 글의 짧은 부분을 직접 골라 ‘내가 남긴 문장’ 액자에 걸 수 있다. 액자 비우기는
  공간의 사본만 지운다. 공유나 서버 전송을 추가하지 않으며 원래 필사 본문은 바꾸지 않는다.
- 큰 책상의 ‘쓰는 인간의 쪽지’에는 준비한 네 편을 주마다 한 편씩 펼친다. 실시간 편지,
  실제 발신자의 새 메시지나 새 콘텐츠 배달로 표현하지 않는다. 연속 방문 보상은 없다.

## 천천히 흐르는 빛과 나의 소리 풍경 · 2026-11-24

사용자가 빛의 흐름·소리의 거리감·기억되는 소리 조합을 우선 적용하도록 요청했다.
공간 안내의 ‘빛과 소리’에서 흐르는 빛과 빗방울·연못의 물·잎과 바람·작은 선율을 고른다.
소리 조합은 기억하고 소리는 방문할 때마다 직접 켠다. 설정을 만지거나 다시 입장하는
행동만으로 소리를 켜지 않는다. 저장 실패는 보이는 선택과 재시도를 유지한다.

선택한 낮/해 질 무렵/비 오는 저녁 안에서 약 12분의 부드러운 빛 순환이 흐른다.
창가의 종이·원목·바닥에는 세계 좌표에 고정된 잎 모양 음영이 움직인다. 주변 빛이
낮아지면 켜 둔 조명의 따뜻함이 또렷해진다. 창가에서 보는 정원과 걸어 들어간 정원은
같은 빛의 진행을 쓴다. 실제 시각·날씨를 조회하거나 자동으로 시간을 바꾸는 기능은 아니다.
동작 줄이기·화면 비활성화에서는 진행을 멈춘다. 흐르는 빛을 끄면 고른 기본 분위기로 둔다.

창가 가까이에서는 빗방울, 정원에서는 물과 잎 소리가 가까워진다. 문을 닫으면 바깥
소리가 낮아지고, 고개를 돌리면 소리의 좌우 방향도 달라진다. 정원 이동 때 반복음을
다시 시작하지 않고 부드럽게 이어 간다. 작은 선율과 잎 소리는 이번에 만든 합성 음원이다.
계절 식재 개편·개인 문장 낭독은 이번 우선 적용 범위에 포함하지 않는다.
