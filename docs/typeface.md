# 쓰는 인간체 개발

## 현재 진행 방식 · 직접 제작

사용자는 외부 의뢰가 아니라 Codex가 직접 제작할 것을 명확히 요청했다.
직접 편집할 수 있는 공통 자모 벡터 원본에서 **개발 견본 0.5**를 다시 만들었다.
외부 연락·발주·계약은 없다. 기존 의뢰 자료는 중단된 초안으로만 남긴다.

첨부 브랜드 보드의 따뜻한 명조 인상, 부드러운 획 끝과 열린 속공간을 참고했다.
현재는 한글 111자, 공백·마침표·쉼표를 지원하는 실제 TTF 개발판이다.
이미지 속 완성 폰트를 복원했다거나 출시용 서체가 완성됐다고 표시하지 않는다.

## 이번에 바꾼 제작 방식

0.1–0.3은 개별 글자 이미지의 윤곽 추적이었다. 글자별 크기는 조정했지만
반복 자모의 획을 직접 통제하기 어려웠다. 0.4에서는 직접 작성한 자모 중심선과
베지어 윤곽을 사용한다. 기존 나눔명조 등의 윤곽은 읽거나 복사하지 않는다.

- 공통 `ㅇ` 타원, `ㄹ` 구조, `ㅅ` 곡선을 여러 글자에서 재사용한다.
- 세로 62 / 가로 34 디자인 단위를 기본으로 하고, 좁은 쌍자음·겹받침은
  밀도 보정을 적용한다. 배치 상자를 바꾼 뒤 획을 그리므로 폭 축소 때문에
  세로획까지 가늘어지는 현상을 줄인다.
- 세로모음·가로모음·복합모음 × 받침 유무의 여섯 배치와 둥근 자음·받침별
  비율 보정을 둔다. 모든 조합의 광학 보정이 끝난 것은 아니다.
- 가로획은 얕은 곡선과 짧게 들린 끝, 세로획은 부드러운 사선 어깨를 사용한다.
- 획 겹침을 합치고 속공간을 유지한 후 실제 TrueType 곡선으로 변환한다.

편집 원본·빌드·지원 문자·재현 명령은
[앱 서체 설명](../assets/fonts/WritingHumanDevelopment-README.md)에 있다.

## 실제 렌더와 제품 적용

`tool/render_typeface_proof_test.dart`가 실제 TTF를 Flutter FontLoader로 읽어
18·23·32·42px 비교, 390px 종이 면, 긴 문장과 겹받침 표본을 렌더한다.
새 표본 문자의 cmap 포함 여부도 확인해 견본 본문에서 대체 폰트가 섞이는
상황을 검사한다. 설명 문구는 나눔고딕이다.

결과는 `artifacts/typeface/reading-v005.png`, `specimen.png`,
`inner-page.png`, `vector-comparison-v005.png`다. 실제 폰트의 Flutter 테스트
렌더이며 앱·브라우저·실기기 실행 화면은 아니다.

사용자의 적용 요청에 따라 개발판을 `assets/fonts`와 `pubspec.yaml`에 연결했다.
Aa → 글꼴 → 쓰는 인간체 · 개발 중에서 선택하며 기본 및 기존 설정은 유지한다.
지원 범위 밖의 한글·숫자·라틴 문자는 번들 나눔명조로 대체 표시한다.
이 대체 표시를 자체 서체 지원으로 집계하지 않는다. 전체 한글·자모 조판,
힌팅·실기기 판독성과 최종 광학 조정은 후속 범위다.

## 이전 실험 보존

0.1–0.3 TTF·매니페스트는 `proof/archive/`에 있다. 이전 이미지와 생성
프롬프트도 `source/`에 보존한다. 이전 결과를 새 직접 제작판의 완성도나
실기기 검증으로 사용하지 않는다. 이번 실행 결과는
[verification.md](verification.md)에 따로 기록한다.

## 0.5 · 종이 시안에 실제 서체 적용

기존 100자 윤곽과 간격을 보존하고, 원래 이미지의 문장·표시에 필요한
`곁·관·깁·니·됨·두·보·싶·씁·저·함` 11자를 공통 자모로 확장했다.
`tool/render_typeface_image_test.dart`가 종이 배경 위 제목·본문·한글 표시를
새 TTF로 렌더한다. 결과는 `artifacts/typeface/applied-page-v005.png`다.
배경은 내장 imagegen으로 문자를 지워 편집했고, 원래 문장을 실제 TTF로 다시 얹었다.
배경의 Aa와 아이콘은 이미지 요소다. 펜은 기존 앱 이미지 자산을 사용했다.
당시의 이미지 시안 기록이다. 이후 실제 앱 연결은 아래 현재 상태를 따른다.
정확한 편집 프롬프트와 파일 해시는 `design/typeface/source/generation-image-v005.json`에 있다.
재현: `flutter test tool/render_typeface_image_test.dart --no-pub`.

## 현재 앱 연결

본문과 브랜드 제목은 개발 서체 선택 시 실제 WritingHumanDevelopment TTF를
사용한다. 도구 화면에는 개발 중과 한글 111자·대체 표시를 명시했다.
기존 글꼴 선택·종이·잉크와 본문을 유지하고 선택만 저장한다.
실제 적용 미리보기는 `?demo=typeface`이며 합성 데이터다.
`test/typeface_asset_test.dart`는 실제 폰트를 로드해 지원 글자의 윤곽이
나눔명조와 다르고 미지원 글자의 픽셀이 나눔명조와 일치하는지 확인한다.
`test/data/editor_disk_test.dart`는 새 선택·본문·위치의 SQLite 재열기를 검사한다.
